# 📋 ПАТЧ-НОУТ v5.7.2 — «F4: ДРЕВО-ПРОФЫ ПОКАЗЫВАЮТСЯ ЗАКРЫТЫМИ»
**Дата:** 14.08.2026 · **Сборка:** POLUS11_SERVER_v5.7.2.zip

> 📌 Правило соблюдено: старые файлы не тронуты.

## 🔒 ПРОБЛЕМА
Профы, открывающиеся через ДРЕВО СЛУЖБЫ, выглядели в F4 как
доступные («ЗАНЯТЬ ДОЛЖНОСТЬ»), хотя у игрока узел/уровень закрыт.
Штатный F4 не имел проверки древа.

## ✅ РЕШЕНИЕ
Новая энтити `polus_p11_f4boot` (доставка клиентам гарантирована)
переопределяет P11FW.OpenJobMenu:
- для каждой древо-профы проверяется: уровень службы + открыт ли узел
  (по данным P11.Tree из P11_TreeSync);
- если закрыто — кнопка показывает **«🔒 ЗАКРЫТО — ДРЕВО СЛУЖБЫ»**,
  кнопка блокируется, клик объясняет причину
  («нужен уровень X» / «закрыта в древе, открой ветку»);
- ранги 14+ (Staff Leader и выше) — древо не блокирует (как на сервере).
