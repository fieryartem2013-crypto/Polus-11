# 💎 ДОНАТ-ВАЛЮТА «ПОЛЮС-ФЛЮКС» (ПФ) — быстрый ответ (v4.10.0 «ГАРАЖ»)

**Заявка владельца:** «добавь донат валюту и меню утилит для её выдачи,
много ассортимента в донат-меню».

## Что уже работает из коробки (без CraftedStore — схема через Discord)
1. **Продажа за реальные рубли** — как раньше: ДИСКОРД канал «#донат»,
   в закрепе — СБП-реквизиты. Пакеты пополнения прямо в игре (F6):
   **500₽ → 100 ПФ**, **900₽ → 180 ПФ (+20%)**, **1500₽ → 320 ПФ (+28%)**.
   Кнопка бросает игрока в ДС (инвайт — `DONATE_URL` в `p11_cl_donate.lua`).
2. **Выдача ПФ за оплату** — ты (или магазин-автомат) начисляешь командой
   в консоли сервера: `p11_fluxgive 76561198XXXXXXXXX 100`.
   Онлайн-игрок получает сразу (тост «+100 ПФ»), оффлайн — при входе.
3. **Трата ПФ** — игрок открывает F6 и покупает в витрине «ПОТРАТИТЬ ПОТОК»:
   VIP-статус (100 ПФ), рубли (+25 000₽ / +60 000₽), РПД, огнемёт,
   меднабор, термос+3 пайка, антидот инкубации, ключ от Як-2 (350 ПФ).
4. **Утилиты выдачи** (стафф, ранг 4+): `p11_utils` — список бойцов онлайн,
   кнопки +100/+500/−100 и произвольная сумма. Каждая выдача пишется
   в журнал станции (`ФЛЮКС-УТИЛИТЫ: кто → кому, сколько`).

## CraftedStore (автомат 24/7) — только шаблон команды другой
В поле «команда сервера» пакета CraftedStore вместо `p11_donorvip`:
```
p11_fluxgive {steamid64} 100
```
(100 = сколько ПФ за пакет; цену ставишь в кабинете магазина.)
Один пакет = одна команда с нужным числом ПФ. Очередь не нужна:
файл `polus11/flux.json` начисляется и оффлайн-игрокам (дождётся входа).
Затем — читай полную инструкцию ниже.

# 💎 ДОНАТ-АВТОМАТ: как подключить CraftedStore к «ПОЛЮС-11»
(ответ на заявку владельца v4.9.2 «ПРИЁМ»: «инструкция подключить краут к игре, чтобы можно было оплатить випку»)

«Краут» = **CraftedStore** (craftedstore.net) — готовый магазин для GMod:
игрок платит на сайте (карты/кошельки — деньги идут НА ТВОЙ баланс магазина,
с него ты выводишь на свою карту), а аддон магазина на сервере сам выполняет
команду выдачи. Карту в игру/код **никогда не вписываем** — принимает платёж
сам сервис.

Серверная сторона УЖЕ готова в сборке v4.9.2: команда-мост **`p11_donorvip`**.
Игрок онлайн → VIP сразу; оффлайн → ложится в очередь и выдаётся при входе
(`garrysmod/data/polus11/donor_queue.json`).

---

## ШАГ 1. Регистрация магазина (5 минут)
1. Зайди на **craftedstore.net** → зарегистрируйся (email + пароль).
2. Нажми **Create Store** → вписывай: имя магазина («ПОЛЮС-11»), валюта
   (RUB), страна. Сайт даст адрес вроде `твоймагазин.craftedstore.net`.
3. В разделе **Payment integrations / Оплата** подключи то, чем будешь
   принимать деньги (у CraftedStore есть готовые интеграции: банковские
   карты, кошельки; комиссию смотри у них). Вывод средств — там же,
   на карту РФ/мир.

## ШАГ 2. Аддон магазина на сервер
1. В кабинете магазина открой раздел **Servers / Серверы → Add server**
   (тип игры: Garry's Mod). Тебе дадут: аддон (zip) + **server key**
   (секретный ключ сервера).
2. Распакуй аддон в `garrysmod/addons/` на сервере:
   `garrysmod/addons/craftedstore/` (или как назовётся папка из их zip).
3. Внутри аддона найди конфиг (обычно `lua/craftedstore/` или
   `sh_config.lua`) и впиши туда твой **server key**. Рестарт сервера.
4. Проверка связи: в консоли сервера появится лог типа
   `CraftedStore: сервер подключён`, а в кабинете сервер станет ONLINE.

## ШАГ 3. Пакет «VIP» c автовыдачей
1. В кабинете: **Products / Товары → Add product**.
2. Имя: `💎 VIP — ПОЛЮС-11`, цена: своя (например 99₽), описание:
   «Секция 💎 VIP-СЛУЖБА в F4 (3 должности), золотой ранг в TAB».
3. Самое главное — поле **Commands / Команда сервера** (она выполняется
   после ОПЛАТЫ). Впиши шаблон с их плейсхолдером SteamID:

   ```
   p11_donorvip {steamid64}
   ```
   Если у CraftedStore в списке плейсхолдеров только `{steamid}` — не беда,
   мост принимает оба формата: впиши `p11_donorvip {steamid}`.

4. Сохрани. Товар заметен на витрине `твоймагазин.craftedstore.net`.

## ШАГ 4. Проверка (без реальных денег)
1. В кабинете у товара есть **тестовая покупка** (или сам купи за копейку
   и сделай refund).
2. После оплаты в консоли сервера: строка `[POLUS-11] ДОНОР: «ник» …
   получил VIP через магазин` + объявление всем «💎 МАГАЗИН: …».
3. Если покупал оффлайн: увидишь `… оффлайн — VIP уйдёт при входе`;
   очередь смотри командой `p11_donorvip list` (от Главы).
4. Тест без магазина: в консоли СЕРВЕРА сам наберёт
   `p11_donorvip STEAM_0:x:yyyyyy` — эффект тот же (так проверяешь мост
   даже до подключения CraftedStore).

## Если не CraftedStore
Тот же мост работает с любым магазином, который умеет «выполнить консольную
команду на сервере по оплате»: **EasyDonate**, **CraftedStore**, самописная
страница с RCON. Команда всегда одна: `p11_donorvip <SteamID>`.

## Правила безопасности (железно)
- **Никаких банковских карт в игре/коде/конфигах сервера.** Карту видит
  только платёжный сервис магазина.
- Server key лежит ТОЛЬКО в конфиге аддона магазина на сервере, не в git.
- Промо-талоны (v4.9.0) — это бесплатные коды из игры; донат-мост — деньги.
  Они друг другу не мешают.

## 💬 Схема: продажа через Discord (v4.9.3 «ГРОШ» — та, что ты просил)
Проще магазина: кнопка в F6 (цена 500₽ / 900₽ / 1500₽) по заявке «при
нажатии кидает на наш дс сервер» — открывает ТВОЙ Discord.

1. **Вставь инвайт своего ДС** в начало файла
   `gamemodes/polus/gamemode/modules/p11_cl_donate.lua`:
   `local DONATE_URL = "https://discord.gg/ТВОЙ_КОД"`
   (в ДС: шестерёнка сервера → Приглашения → «Не ограничен по времени»).
2. В ДС сделай канал **#донат-магазин** с закреплённым прайсом:
   `💎 VIP — 500₽  👑 VIP+ — 900₽  🛡 ПОКРОВИТЕЛЬ — 1500₽`
   и там же — КУДА кидать деньги: **номер карты или СБП-привязка**
   (карту видят только твои участники ДС, НИКТО в игре её не трогает).
3. Игрок зашёл в ДС → перевёл → прислал тебе скрин чека + свой Ник/SteamID
   (SteamID игрок видит в консоли командой `status`).
4. Выдача: в консоли СЕРВЕРА `p11_donorvip STEAM_0:x:…` (есть лог+очередь
   на оффлайн-игрока) или вручную `p11_rank ник vip`. Лог пишется — споры
   решаются по `DonorQueue`/логам сервера.
5. Права в ДС: канал-модерация — только у тебя/правой руки, чтобы «от
   имени магазина» не колол цены чужаки.

## Что теперь написано в игре
- В витрине F6 под талоном одна строка-подсказка про магазин.
- Выдача ручного VIP без магазина по-прежнему работает: `p11_rank <ник> vip`.
