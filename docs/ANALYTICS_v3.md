# 📊 АНАЛИТИКА ПРОЕКТА ПОЛЮС-11 — v3 (единый гейммод)

Дата: 05.08.2026. Сборка: **3.2** (P11FW 1.4.0 + POLUS11 2.6, гейммод `polus`).

## 0. Итерация v3.2 — фракции, Нечто 2.0 (маскировки), интро, UI

| # | Изменение | Детали |
|---|---|---|
| 1 | **ФРАКЦИИ — создаются в игре** | новая вкладка админки «ФРАКЦИИ»: имя/цвет/порядок/описание, сохранение в `data/polus_framework/factions.json`, синк всем клиентам. Технически фракция = расширенная категория: F4, скорборд (TAB) и админка группируются по ним сами. Встроенные: Гарнизон/Учёные/Без назначения — неудаляемы |
| 2 | **Обновлённое админ-меню** | 5 вкладок: ИГРОКИ • **ДЕЙСТВИЯ** (лечить/возродить/притащить к себе/тп к игроку/заморозка/убить — сети act 14-19) • ДОЛЖНОСТИ (поле «Фракция») • **ФРАКЦИИ** • УТИЛИТЫ |
| 3 | **Маскировка ВСЕМ формам Нечто** | единый `POLUS11.ToggleMask`: R у Поглотителя/Споровика, ПКМ-меню у Имитатора, чат `!маскировка`, консоль `p11_mask`. У каждой формы СВОЯ модель монстра (имитатор=classic, поглотитель=poison, споровик=fast, разделённый=fast_torso). Замаскированный Поглотитель теряет тяжёлое тело (100 хп/обычная скорость) — полная имитация человека |
| 4 | **HUD НЕЧТО** (`p11_cl_thinghud`) | красная панель: форма, состояние (ИНКУБАЦИЯ/МАСКИРОВКА/ЯВЛЕН), полоски кулдаунов крика и смены формы (NWFloat-синк), шкала спор, подсказки клавиш; при явленной форме — пульсирующая красная рамка экрана |
| 5 | **ИНТРО** (`p11_cl_intro`) | кинематографичная заставка на первом входе: печатающийся лор 1982, эмбиент `ambience_base`, свечение логотипа, пропуск любой клавишей, `p11_intro 0` — отключить; сервер шлёт 1 раз за сессию на игрока |
| 6 | **Скорборд по фракциям** | TAB теперь секциями: цветной заголовок фракции + счёт + строки игроков с должностями; фолбэк на плоский список без фреймворка |
| 7 | **«Разрыв» споровика → `!разрыв`** | R отдан под маскировку (единый стандарт), саморазрыв вынесен в чат-команду с кулдауном 20 с |

Баги, пойманные в ходе итерации: автозакрытие интро бездействовало (странная формула); `net.Receive("P11_FearFX")`-заглушка в HUD Нечто СТЁРЛА бы обработчик паники (net.Receive перезаписывает, не складывает) — удалена; у Spore R конфликтовала с разрывом — разнесено.

Метрики: **72 lua-файла, 0 ошибок luac 5.1**; новые звуки (`ambience_base`, `lever1`, `zombie_voice_idle2`) сверены с HL2 Sound List.

| 6 | **Фикс потенциального конфликта** | из админ-гейтов убран `PlayerSpawnObject`: если базовый `gm_spawn` маршрутизирует через него, переопределение могло сломать спавн — теперь решают только типовые гейты |

## 5. Известные риски альфы

1. **Ни разу не запускалось в Garry's Mod** — первый стартап может показать
   ошибки, которые статика не ловит (nil-поля в рантайме, порядок хуков).
   → прогнать смоук-тест из ALPHA_READY.md раздел 2, прислать `[POLUS][ERROR]`.
2. **Баланс классов Нечто** (hp Поглотителя 170, радиус спор 130, порог 100)
   подобран на глаз — калибровка после первых игр.
3. Двойная установка со СТАРЫМИ аддонами (`polus_framework`, `polus11`)
   вызовет дубли хуков — в INSTALL.md прямым текстом: удалить.
4. `team.SetUp` лимит: кастомные профессии занимают id 200+ (потолок 256) —
   реалистично до ~50 профессий, дальше нужен рефактор.
