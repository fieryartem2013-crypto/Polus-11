## 🔉 1) ГРОМКО — ПО УМОЛЧАНИЮ МАКСИМУМ (1.0)
Жалоба: «песня играет очень тихо». Теперь громкость по умолчанию
**1.0 (максимум)**, при желании регулируется: `!музгром 0.5`.
Демо-треки в сборке перегенерированы — громче и без заниженной
амплитуды.

## 🔁 2) ТРЕК ИГРАЕТ ОДИН РАЗ (не эмбиент)
Жалоба: «повторяется после окончания мелодии как эмбиент».
- новый клиентский плеер (sound.PlayFile, `EnableLooping(false)`) —
  трек проигрывается ровно один раз и останавливается;
- старые демо имели повторяющийся паттерн (три гудка/три волны) —
  заменены на одиночные сигналы;
- повтор по кругу — ТОЛЬКО по команде **`!музцикл 1`** (кому нужна
  фоновая музыка — включает сам), `!музцикл 0` — вернуть один раз.

## 🎛 КОМАНДЫ (админ)
| Команда | Что делает |
|---|---|
| `!музыка` | список + что играет + повтор/громкость |
| `!музыка 2` / `!музыка polus_ost_1` | по номеру / по имени |
| `!музыка стоп` / `!музстоп` | остановить |
| `!музгром 1.0` | громкость 0..1 (по умолчанию 1.0) |
| `!музцикл 1` / `!музцикл 0` | повтор по кругу вкл / выкл |
