# 🔧 HANDOFF: что жаловался пользователь + известные проблемы
*Документ для другого ИИ/разработчика. Код: GitHub `fieryartem2013-crypto/test` (папки `prof_npc/`, `thing_swep/`, `polus11/`).*

> **ОБНОВЛЕНИЕ 04.08.2026 (v2.1):** проведён полный статический аудит репозитория — см. `AUDIT_v2.1.md`. Исправлено 8 реальных багов: огнемёт не поджигал и его бак пустел за 3 сек; скорость паука и бафф темноты «залипали» после смерти; битые пути звуков `npc/poisonzombie/` → `npc/zombie_poison/`; `/р ` резала первый символ; трекер трупов мог метить чужие ragdoll'ы; колба не садилась в руку; кислота летала криво. Пункты B1/B4/B5 ниже частично закрыты этим патчем.

> ⚠️ **Контекст:** весь Lua писался «вслепую» — проверялся ТОЛЬКО синтаксисом (luac -p, Lua 5.1). В реальном Garry's Mod **не запускался**. Runtime-ошибки (неправильные имена API/хуков, звуковые пути, эффекты) очень вероятны.

## A. ПРЯМЫЕ ЖАЛОБЫ ПОЛЬЗОВАТЕЛЯ

### A1. «Энтити нету» (жаловался 2 раза)
- **Оригинальная причина (мой баг):** энтити лежали по пути `lua/entities/entities/<name>/`, а GMod регистрирует их только в `lua/entities/<name>/`. Исправлено в коммите `eecd90f` (перенесены `mv` вверх на уровень).
- **После фикса пользователь жаловался снова** («не Энтити не механики нету»). Возможные причины (проверять в таком порядке):
  1. **Двойная вложенность при установке**: `garrysmod/addons/polus11/polus11/...` — пользователь распаковал zip «сугубо». Нужная структура: `garrysmod/addons/polus11/lua/autorun/polus11_loader.lua`.
  2. **Нет полной перезагрузки карты/сервера** после замены файлов.
  3. Смотрит не туда: энтити в Q → вкладка **«Энтити» (Entities)** → категория «ПОЛЮС-11», и помечены `AdminOnly` (видны только админу; в одиночной игре пользователь админ).
- **Статус:** исправлено по коду, ⏳ ждёт верификации в игре. Диагностика: `polus11_status` в консоли + баннер `[POLUS-11 v2.0]` при входе; загрузчик пишет `[POLUS-11][ERROR] файл -> ошибка` для каждого сломанного файла.

### A2. «У Нечто механики нету / как стать человеком из нечего — так и осталось»
- **Оригинальная причина (мой баг):** в `weapon_polus11_thing/shared.lua` после раскрытия формы монстра стоял таймер 20 сек на авто-возврат (`POLUS11_HideThing`). Если Нечто раскрылось, а потом съело труп и взяло его модель — таймер через 20 сек перезаписывал модель на старую `P11_SavedModel`: украденная личность слетала. Исправлено: при `EatCorpse` и при `RestoreTrueIdentity` обнуляются `P11_Revealed/P11_RevealedAt/P11_SavedModel`.
- **Статус:** исправлено в v2.0, ⏳ ждёт верификации. Проверка: заразиться (или `polus11_infect <id>`), убить бота/игрока, R по трупу → внешность должна держаться дольше 20 сек, R без трупа → вернуть свою модель.

### A3. GitHub: «не могу создать репозиторий»
- Не баг аддона: fine-grained PAT пользователя не имеет права Administration (Repository creation). Workaround использован: пуш в существующий приватный репозиторий `test`. Для новых репо токен нужно перевыпустить с доступом Administration: Write.

## B. САМЫЕ ВЕРОЯТНЫЕ RUNTIME-ПРОБЛЕМЫ (не пойманы luac)

### B1. Несуществующие звуковые файлы (EmitSound тихо промолчит, но атмосфера потеряется)
Проверить в игре через `snd_show 1` / `playsoundscape`. Под подозрением:
- `ambient/machines/diesel_engine_idle1.wav` (генератор, `polus11_generator/init.lua`)
- `ambient/energy/weld1.wav`, `ambient/energy/spark1..6.wav`
- `ambient/levels/canals/toxic_slime_*` (sizzle2/3, gurgle2/4)
- `ambient/fire/mtov_flame2.wav` (огнемёт)
- `npc/poisonzombie/pz_alert1/2.wav`, `npc/zombie/zo_attack1/2.wav`, `npc/fast_zombie/leap1.wav`, `npc/barnacle/barnacle_gulp2.wav`, `npc/combine_soldier/die3.wav`, `buttons/lever1..5`, `buttons/combine_button1..3`
- `physics/flesh/flesh_squishy_impact_hard1..4.wav`
Если каких-то нет — замена на существующие аналоги из `sound/` HL2.

### B2. util.Effect имена
Используются: `BloodImpact`, `bloodspray`, `sparks`, `smoke_trail`, `flame_gib_01` (огнемёт!), `propspawn`. `flame_gib_01` — самый сомнительный; если эффекта нет — убрать/заменить на `sparks` или клиентские частицы.

### B3. Частицы огнемёта (`weapon_polus11_flamethrower`)
- `ParticleEmitter:Add("effects/fire_cloud1", ...)` / `"sprites/light_glow02_add"` — пути могут отличаться. Если огня не видно — первым смотреть сюда.
- Модель `models/weapons/c_irifle.mdl` + attachment `"muzzle"` — если аттачмента нет, есть fallback на ShootPos.
- `ents.FindInCone(...)` — сигнатуру проверить в своей версии GMod.

### B4. Entity-зависимости
- `CreateSound(self, ...)` + `SoundLoop:PlayEx` на генераторе; при аварии `Stop` — ок.
- `polus11_generator`: `self:SetHealth/SetMaxHealth` на anim-энтити + `OnTakeDamage` — работает, но проверить вызов хука на base_anim (может потребоваться `ENT.Damage` через `TakeDamageInfo` фильтр).
- `SetModelScale` на `npc_fast_zombie` (босс) — визуально работает, но **хитбокс/корпус не масштабируется**; плюс **нужен navmesh** (`nav_generate`), иначе босс стоит столбом.

### B5. Трупы (`prop_ragdoll`) и поглощение
- Привязка личности: `PlayerDeath` → `timer.Simple(0)` → ближайшая ragdoll в радиусе 80 без `P11_Identity`. Если двое умирают рядом одновременно — возможна перепутанная личность. Если мод удаляет трупы (corpse cleanup плагин!) — поглощение работать не будет: **проверить совместимость с corpse-аддонами сервера**.
- Трассировка трупа в `TraceCorpse` (TraceHull 140 ед) — на странных позах рагдолла может попадать рядом; при жалобах добавить визуальный маркер.

### B6. DarkRP-зависимые места (тихо деградируют в Sandbox — это нормально, но проверить)
- `ply:setDarkRPVar("rpname", ...)` в обёртках pcall — в DarkRP имя подменяется; в Sandbox только наш чат-хук + ТАБ.
- `ply:getJobTable()` использован в `POLUS11.IsScientist/IsEngineer` — guard на `DarkRP` есть.
- `DarkRP.notify` с fallback на ChatPrint.

### B7. Голос рации
`PlayerCanHearPlayersVoice` модифицирует дальность — зависит от серверных `sv_voice`/`voice_3d` настроек и аддонов голосового чата (если стоит другой voice-addon, возможен конфликт приоритетов).

### B8. NW-видимость (по дизайну, но важно понять)
`P11_Infected/P11_InfActive` и др. это `SetNWBool` — **читаются любым клиентским скриптом**. Для альфы доверенных людей ок; читерам видно всё. Полное сокрытие = отдельная большая работа (сервер-eдинственное хранилище + точечный net к заражённым).

### B9. prof_npc отдельные замечания
- `LookupSequence("idle_all_01")` и пр. — на кастомных моделях может не найтись → статичная модель (T-pose допустим, но можно fallback на `self:SelectWeightedSequence(ACT_IDLE)`).
- `ResetSequence` на не-HL2 моделях иногда не анимирует.
- Блокировка F4 живёт только за счёт `ShowSpare2 → return false`; если в сборке есть другой аддон, открывающий чужое меню на F4 — конфликт.

### B10. Скорборд (`cl_scoreboard.lua`)
- В DarkRP самоотключается (`if DarkRP then return end`). В Sandbox заменяет стандартный ТАБ; если у пользователя стоит другой scoreboard-аддон — перетирание хуков, кто последний — тот и рисует.
- Kill feed (DEATHNOTICE) палит настоящие ники — закрыт опцией `HideKillFeed = false` (можно включить true).

## C. ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ (не баги)

1. Нативные защиты нет: NW-флаги (см. B8).
2. Босс/зомби-NPC нужен navmesh на карте (`nav_generate`).
3. Генератор/стол/бочки: AdminOnly-спавн; сохранение координат (`sv_persist.lua`) пишет в `data/polus11/station_<map>.json`.

5. thing_swep (старый аддон) и polus11-классы — ДВЕ ПОХОЖИЕ, НО НЕЗАВИСИМЫЕ системы маскировок. **Одновременно ставить НЕ рекомендуется** (дублирующаяся логика NW/меню). На сервер оставить одно.

## D. БЫСТРАЯ ДИАГНОСТИКА НА ЖИВОМ СЕРВЕРЕ

1. Вход → должен быть чат `[POLUS-11 v2.0] Аддон активен`
2. Консоль: `polus11_status` → версия, энтити на карте, заражённые
3. Консоль при старте карты: искать `[POLUS-11][ERROR] <файл> -> <ошибка>` — сразу виден сломанный модуль
4. Q → «Энтити» → «ПОЛЮС-11» (видно только админу)
5. F4/настройки: убедиться, что `polus11` НЕ установлен дважды (старый + новый zip рядом)
