## 🐛 ГЛАВНОЕ: ОШИБКА «attempt to call local 'v' (a boolean value)» x72
Причина: фикс порядка HUD (v5.8.14, энтити hudfix) хранил метку
готовности **прямо в таблице хуков HUDPaint** (`hud.P11_HudFixDone = true`).
Движок при каждом вызове HUDPaint итерирует таблицу и пытается
вызвать каждое значение как функцию — натыкался на `true` → ошибка
**каждый кадр** (72+ за секунду = «миллиард ошибок»).

Исправлено (`gamemodes/darkrp/entities/entities/polus_p11_hudfix/cl_init.lua`):
- метка готовности перенесена **во внешнюю переменную** `P11.HudFixDone`;
- в таблицу хуков больше ничего не кладётся, кроме функций;
- заодно сборка хуков теперь берёт только функции (страховка).

**Из-за этой ошибки клиент падал → F4 не перестраивался → фракция
ООН/ГОК не появлялась.** После фикса фракция должна отобразиться.

## 🔍 ДИАГНОСТИКА ООН/ГОК: p11_ungocdiag
Админ пишет в консоль/чат `p11_ungocdiag` — покажет:
- фракция ООН/ГОК: есть/нет;
- фракция Осовец: вырезана/осталась;
- сколько проф ООН/ГОК зарегистрировано;
- немецкое оружие в ларьке: вырезано/осталось.
