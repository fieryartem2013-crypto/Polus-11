# 📋 ПАТЧ-НОУТ v5.8.12 — «РАДИО СТАНЦИИ (СЛЫШНО ВСЕМ)»
**Дата:** 16.08.2026 · **Сборка:** POLUS11_SERVER_v5.8.12.zip

> 📌 Старые файлы не тронуты, всё новое.

## 📻 ЧТО СДЕЛАНО
По заявке: «сделаю мод, который делает радио, которое будет
слышно всем». Готово — **РАДИО СТАНЦИИ**:
- единый эфир, который слышат ВСЕ игроки (фоновое радио станции);
- `polus_ost_1` — главный трек, **повтор по кругу** (13:14 ок);
- автовключение при старте/смене карты, каждому заходящему — сразу;
- громкость 1.0 (макс).

## 🔍 ПОЧЕМУ РАНЬШЕ БЫЛО «ПАПКА ПУСТА»
Звуки лежали только в папке гейммода (`gamemodes/darkrp/sound/...`),
а **сервер её не видит** — она не входит в игровой search path.
Скрипт теперь:
- добавляет папку гейммода в search path (страховка);
- ищет звуки по ВСЕМ путям: `sound/**`, `sound/polus11/music/*`,
  `gamemodes/<гейммод>/sound/**` — файл найдётся, где бы ни лежал;
- раздаёт найденное клиентам (resource.AddFile);
- пересканирует каждые 30 сек (новый файл — без рестарта).

## 📥 КУДА КИНУТЬ ФАЙЛ (надёжно)
**`garrysmod/sound/polus11/music/polus_ost_1.mp3`** — общая папка
сервера, её видно всегда. (Найдёт и в папке гейммода.)

## 🎛 КОМАНДЫ (админ)
| Команда | Что делает |
|---|---|
| `!радио` | список треков + что в эфире |
| `!радио 2` / `!радио polus_ost_1` | сменить трек |
| `!радиостоп` / `!музстоп` | выключить |
| `!радиогром 1.0` / `!музгром` | громкость |
| `!музыка` / `!музцикл` | старые команды тоже работают |

Старые команды `!музыка` сохранены (алиас радио).

| Файл | Роль |
|---|---|
| `lua/autorun/server/p11_sv_radiostation_spawn_v5812.lua` | радио: поиск по всем путям, эфир, команды, диагностика |

## ⚠️ УСТАНОВКА
1. Удали на сервере папки `garrysmod/gamemodes/darkrp/` и `garrysmod/lua/autorun/`.
2. Скопируй новую `garrysmod/` ЦЕЛИКОМ (в ней есть `sound/polus11/music/` с демо).
3. Кинь `polus_ost_1.mp3` в `garrysmod/sound/polus11/music/`.
4. Перезапусти сервер. Клиентам — перезапустить игру + удалить cache/.
