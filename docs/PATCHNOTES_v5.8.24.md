# 📋 ПАТЧ-НОУТ v5.8.24 — «ФИКС БОДИГРУПП (unpooled P11_BGSet)»
**Дата:** 19.08.2026 · **Сборка:** POLUS11_SERVER_v5.8.24.zip

> 📌 Экстренный фикс по заявке владельца.

## 🐛 ПРОБЛЕМА
При клике в меню бодигрупп («Внешность») — десятки ошибок:
`net.Start with unpooled message name! (Did you forget util.AddNetworkString?)`
на `P11_BGSet` (строки 99/130 cl_init).

Причина: канал `P11_BGSet` регистрировался только в
`lua/autorun/server/p11_sv_bgmenu_spawn_v577.lua`. Если этот файл
не доезжал до сервера (старая установка, конфликт папок, сервер
не перезапущен) — клиент не знал имя → каждая отправка падала.

## ✅ ФИКС
1. **Регистрация продублирована** в `shared.lua` энтити
   `polus_p11_bgmenu` (`if SERVER then util.AddNetworkString(...) end`)
   — shared энтити грузится на сервере через init.lua энтити,
   гарантированно, вместе с самой системой бодигрупп.
2. **Клиентская отправка защищена** (pcall): если канал вдруг не
   зарегистрирован — молча пропускаем, БЕЗ спама ошибок. Смена
   бодигруппы локально у себя видна в любом случае.

## ⚠️ УСТАНОВКА (ВАЖНО)
1. Удали на сервере папки `garrysmod/gamemodes/darkrp/` и `garrysmod/lua/autorun/`
   (**обязательно** — старые файлы из прошлых установок могли остаться).
2. Скопируй новую `garrysmod/` ЦЕЛИКОМ.
3. ПЕРЕЗАПУСТИ сервер (без рестарта новый autorun не подхватится).
4. Клиентам — перезапустить игру + удалить cache/.
