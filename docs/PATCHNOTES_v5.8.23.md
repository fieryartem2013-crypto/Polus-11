# 📋 ПАТЧ-НОУТ v5.8.23 — «ПРАВА АДМИНИСТРАЦИИ: ВЫДАЧА РАНГОВ»
**Дата:** 19.08.2026 · **Сборка:** POLUS11_SERVER_v5.8.23.zip

> 📌 Правка по заявке владельца.

## 🎖 ЧТО БЫЛО
Выдавать ранги мог только **Куратор+ (12+)** — порог
`Config.RankManageLevel = 12`. Поэтому **не могли выдавать**:
Global Admin (7), Deputy Staff Leader (10).

## ✅ ЧТО СТАЛО
`fw_sh_ranks.lua` — выдавать ранги (ниже своего) теперь могут
(список `RANK_MANAGERS`):

| Ранг | Уровень |
|---|---|
| Global Admin | 7 |
| Deputy Staff Leader | 10 |
| Global Eventmaster | 12 |
| Curator | 12 |
| Chief Curator | 13 |
| Staff Leader | 14 |
| Chief Staff Leader | 15 |
| Глава Проекта | 16 |

Правило прежнее: **выдать можно ранг НИЖЕ своего** (Глава — все
кроме Глав). Super Admin (6) и ниже по-прежнему не могут.

## 🖥 КЛИЕНТ (fw_cl_admin.lua)
- вкладки **«ИГРОКИ»** и **«АДМИНКИ»** (выдача рангов) теперь
  открываются по `CanManageRank` (раньше — только 12+);
- подписи обновлены: «Выдать может: Global Admin, Deputy Staff
  Leader, Global Eventmaster, Куратор+, штаб (ниже своего ранга)»;
- табель о рангах (RankRightsInfo) показывает «выдача рангов»
  тем же, кто реально может.

## ⚠️ УСТАНОВКА
1. Удали на сервере `garrysmod/gamemodes/darkrp/` и `garrysmod/lua/autorun/`.
2. Скопируй новую `garrysmod/` ЦЕЛИКОМ.
3. Перезапусти сервер. Клиентам — перезапустить игру + удалить cache/.

## ПРОВЕРКА
- Выдай себе `global_admin` → вкладка «ИГРОКИ» доступна, p11_rank работает.
- `staff_leader` → может выдавать ранги ниже 14.
- `super_admin` (6) → НЕ может (как раньше).
