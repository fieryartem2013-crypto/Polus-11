## 🧠 ПАМЯТЬ ЖЕРТВЫ (идея №15)
Новый серверный модуль `lua/autorun/server/p11_sv_victmemory_v526.lua`:

- При смерти игрока снимается «снимок»: где был (зона станции), на
  дежурстве ли, в розыске, звание смены.
- При поглощении Нечто получает ПАМЯТЬ: ник + должность + место + пост +
  документ (до 3 личностей за рейс).
- Команда твари **`!память`** — показать все фрагменты → врать в допросах
  по РП убедительнее (НКВД ловит на нестыковках).
- Авто-шепот при поглощении: краткая сводка личности.
