## 🔍 НАСТОЯЩАЯ ПРИЧИНА «СТАРОГО UI»
В v5.5.6 я положил весь новый UI в `cl_init.lua` энтити
`polus_p11_uiboot`. НО код в cl_init энтити выполняется на клиенте
ТОЛЬКО КОГДА ЭНТИТИ СОЗДАНА В МИРЕ. Энтити никто не спавнил —
поэтому новый UI на клиентах НЕ выполнялся, и ты видел старый.

## ✅ РЕШЕНИЕ v5.5.7 — СПАВНЕР
Новый серверный файл `p11_sv_uiboot_spawn_v557.lua`:
- при старте сервера (InitPostEntity) и после очистки карты
  (PostCleanupMap) создаёт энтити `polus_p11_uiboot` **невидимо,
  глубоко под картой** (0,0,-20000);
- клиенты получают эту энтити → её `cl_init.lua` (весь мастер-UI)
  ВЫПОЛНЯЕТСЯ на клиенте ПОСЛЕ загрузки гейммода → новый UI
  (F4 с карточкой, C-меню, таблички НПС, замена знаков) включается.

Это тот же механизм, которым работают твои НПС (ларёк/кадровик) —
их cl_init рисует таблички, потому что энтити существуют на карте.

## 🎨 ЧТО ВКЛЮЧИТСЯ (когда UI заработает)

  кнопка ВЗЯТЬ, ПЕРЕЛИВАЮЩАЯСЯ рамка (HSV-градиент).

## ⚠️ УСТАНОВКА (обязательно)
1. На СЕРВЕРЕ удали папки: `garrysmod/lua/autorun/` и
   `garrysmod/gamemodes/polus/` (убить старые файлы, вкл. v552).
2. Скопируй новую `garrysmod/` из архива ЦЕЛИКОМ.
3. Перезапусти СЕРВЕР.
4. КЛИЕНТАМ: закрыть игру, удалить `garrysmod/cache/`, зайти заново
   (иначе клиент возьмёт старые файлы из кэша).
