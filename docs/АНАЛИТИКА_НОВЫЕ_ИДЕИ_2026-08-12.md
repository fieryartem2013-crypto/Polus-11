## А. ПСИХОЛОГИЧЕСКИЙ ХОРРОР (паранойя глубже)

### А1. «Шёпот станции» — фейковые сигналы 🟢
Иногда игроку (не Нечто!) приходит личное сообщение «от станции/Центра»:
«Сотрудник, вы последний, кто видел Петрова живым. Не рассказывайте никому».
Оно может быть от системы… а может — от Нечто, которое выбрало жертву.
- **Эффект:** игрок не знает, реален ли источник → паранойя, тихие разговоры.
- **Реализация:** серверный таймер + случайный выбор, `net` лично игроку,
  стиль «как системные» (одинаковый префикс). Нечто получает команду
  «!шепот <ник> <текст>» — те же каналы, неотличимо.
- **Сложность:** низкая. **Ценность:** высокая (ядро жанра).

### А2. Двойники и галлюцинации (клиентские миражи) 🟡
В редкие «тёмные» моменты клиент рисует **фантомного игрока** (копия
модели/ника настоящего бойца) в коридоре — при приближении исчезает.
- **Эффект:** «я видел его в коридоре, а он говорит, что был в столовой» —
  идеальные завязки для допросов по РП.
- **Реализация:** клиентский рендер `ents.Create` + `SetNoDraw(false)` для
  фантома, или простая отрисовка через HUDPaint (без энтити). Ник
  берётся из живого ростера.
- **Сложность:** средняя. **Ценность:** высокая (уникально для GMod).

### А3. «Последние слова» — предсмертные записки 🟢
При смерти (не от Нечто) игрок может оставить записку (до 200 символов),
которая **выпадает на месте смерти** и читается другими (E).
- **Эффект:** «он успел написать: „не верь медику“…» — сюжетные крючки,
  улики для НКВД, триггеры паранойи.
- **Реализация:** энтити-записка (можно переиспользовать `polus_p11_clue`
  или новый свеп-бумага) + простой текст.
- **Сложность:** низкая-средняя. **Ценность:** средняя-высокая.

### А4. Личные дневники — читаются при обыске 🟡
У каждого бойца в инвентаре «личный дневник» (заметки). НКВД при обыске
может прочитать **последние записи** владельца.
- **Эффект:** игроки реально пишут в дневник (подозрения, планы) — при
  обыске это становится уликой/компроматом. РП-следствие оживает.
- **Реализация:** поле в `P11_CharDesc`/отдельный сейв + окно ввода
  (C-меню) + чтение через обыск НКВД.
- **Сложность:** средняя. **Ценность:** высокая (уникально).

## Б. ДВУСТОРОННЯЯ ОХОТА (Нечто vs люди)

### Б1. Следы Нечто + УФ-фонарик НКВД 🟡
Нечто оставляет **следы** (капли, отпечатки) в местах, где проявлялось/
убивало. НКВД с «УФ-фонариком» (свеп-фонарик) видит их светящимися и
может идти по следу (следы исчезают через 5–10 мин).
- **Эффект:** охота становится ДВУСТОРОННЕЙ — не только Нечто охотится,
  но и НКВД может выследить тварь. Баланс паранойи.
- **Реализация:** спавн невидимых маркеров (энтити или записи координат)
  при `Polus11.ThingDevoured`/проявлении; свеп-фонарик рисует маркеры.
- **Сложность:** средняя. **Ценность:** высокая (меняет мету).

### Б2. Датчики движения / сигнализации 🟢
Расставляемые (админом или через крафт) **датчики**: при проходе Нечто
(или любого) рядом — писк/уведомление ближайшим патрульным.
- **Эффект:** оборона станции, ночные смены спокойнее; Нечто учится
  обходить датчики. Новый виток противостояния.
- **Реализация:** энтити-датчик с радиусом + проверка `IsThing`.
- **Сложность:** низкая-средняя. **Ценность:** средняя.

### Б3. «Живая карта» станции на терминале 🟡
Терминал (уже есть) получает вкладку **«СОСТОЯНИЕ СТАНЦИИ»**: свет
по секциям (горит/нет), температура (холодно/норма), целостность
(шлюзы), кто на дежурстве (список постов).
- **Эффект:** игроки реально смотрят карту, планируют, замечают
  «странности» (секция обесточена — кто-то саботирует). Центр
  управления станцией оживает.
- **Реализация:** серверные глобалы (уже есть `P11_Blackout`, добавить
  температуру/статусы) + клиентская вкладка в терминале.
- **Сложность:** средняя. **Ценность:** высокая (многослойная).

## В. НОВЫЕ ЦИКЛЫ КОНТЕНТА

### В1. Экспедиции на поверхность 🟡
Периодически (или по команде админа) открывается **«ВЫХОД НА ПОВЕРХНОСТЬ»**:
группа (2–4) выходит за ресурсами (ящики, детали, топливо) на ограниченное
время; наверху — буря, мороз (уже есть система холода!), возможен Нечто.
- **Эффект:** новый командный цикл, риск/награда, «кто вернётся» —
  классика жанра.
- **Реализация:** зоны (p11_arrival уже умеет точки) + таймер + дроп
  ресурсов + усиленный холод.
- **Сложность:** средняя. **Ценность:** высокая.

### В2. «Голос станции» — авто-радио 🟢
Раз в 30–60 мин «диктор» объявляет сводку: **сгенерированную из реальных
событий дня** (кто на дежурстве, сколько тестов крови, происшествия,
«пропал без вести: …»).
- **Эффект:** станция «живая», новости становятся частью РП; игроки ждут
  сводку и обсуждают.
- **Реализация:** серверный сбор статистики (уже частично есть счётчики)
  + текст в `P11_Announce` (труба есть).
- **Сложность:** низкая. **Ценность:** средняя-высокая (атмосфера).

### В3. Телеграф/морзянка между станциями 🟡
На терминале — режим **«СВЯЗЬ С БОЛЬШОЙ ЗЕМЛЁЙ»**: игрок передаёт
зашифрованное сообщение (морзянка-миниигра), которое **может перехватить
радист** другой стороны (или Нечто-маскировка).
- **Эффект:** секретные договорённости, перехват, шпионаж. РП-каналы
  глубже, чем чат.
- **Реализация:** миниигра ввода (есть `MiniStart`), перехват через
  рацию/радиста.
- **Сложность:** средняя. **Ценность:** средняя.

## Г. СОЦМЕХАНИКИ (РП глубже)

### Г1. Система доверия — метки в TAB 🟡
В TAB у каждого бойца — **шкала доверия** (по 5): меняется от действий
(поймал Нечто → +, подставил → −, помог → +). Визуально: цветная точка/
полоска рядом с ником.
- **Эффект:** «этому верят», «этот странный» — паранойя получает
  социальный инструмент; новички видят, кому доверять.
- **Реализация:** серверный счётчик (наподобие playtime) + NWInt + отрисовка
  в TAB (board уже кастомный).
- **Сложность:** средняя. **Ценность:** высокая (соцслой).

### Г2. Карточка персонажа при старте 🟢
При первом входе — **анкета**: имя, откуда, кем был «на Большой Земле»,
пара фактов (семья/профессия/секрет). Хранится и видна в досье НКВД.
- **Эффект:** у каждого есть «биография» для РП; допросы глубже;
  Нечто, скопировав личность, получает и биографию (см. память жертвы).
- **Реализация:** расширение `P11_CharDesc` (уже есть анкета) — добавить
  поля-вопросы.
- **Сложность:** низкая. **Ценность:** средняя-высокая.

### Г3. Кооперативные задачи (2+ игрока) 🟢
Некоторые дела требуют **вдвоём**: перенос тяжёлого ящика (оба держат E),
подъём раненого (один тащит, другой прикрывает), ремонт с ассистентом.
- **Эффект:** команда > одиночка; напарничество получает смысл.
- **Реализация:** проверка «второй рядом и тоже жмёт E» в существующих
  минииграх (MiniStart уже умеет).
- **Сложность:** низкая-средняя. **Ценность:** средняя.

### Г4. «Паёк как валюта» — меновая торговля 🟢
Тушёнка/паёк становятся **меновой единицей** между игроками: обмен
«паёк ↔ патроны/материал» напрямую (уже есть обмен `!обмен` — добавить
паёк в список обмениваемого + подсказки).
- **Эффект:** живой чёрный рынок, экономика «натуральная», РП-сделки.
- **Реализация:** добавить паёк/материалы в `!обмен` (сервер уже
  валидирует предметы).
- **Сложность:** низкая. **Ценность:** средняя.

## Д. ЖИЗНЬ СТАНЦИИ (атмосфера)

### Д1. Динамическая музыка по фазе 🟢
Фоновая музыка/эмбиент меняется по фазе станции: спокойствие → лёгкий
гул → тревога → паника (уже есть фазы `P11_Phase`). Громкость/трек —
клиентский выбор, легко.
- **Эффект:** атмосфера «на слух», смена настроения без слов.
- **Реализация:** клиентский `surface.PlaySound`/`sound` по глобальной
  фазе (хук на изменение).
- **Сложность:** низкая. **Ценность:** средняя (полировка).

### Д2. Читаемые компьютеры/логи станции 🟢
Несколько терминалов с **историей станции**: дневники прошлых зимовок,
рапорты, «исчезновения» — читабельные экраны (как книги).
- **Эффект:** лор, новички погружаются в мир; материал для РП-расследований.
- **Реализация:** клиентское окно с текстом (как F1-справка, готовый UI).
- **Сложность:** низкая. **Ценность:** средняя.

### Д3. Кино/фото-режим для стримеров 🟢
Команда `!кино` — скрыть HUD/никомы/частицы, зафиксировать камеру —
для красивых кадров и клипов.
- **Эффект:** стримеры делают «моменты станции» → приток аудитории.
- **Реализация:** клиентский тумблер отрисовки (готовые хуки).
- **Сложность:** низкая. **Ценность:** средняя (маркетинг).
