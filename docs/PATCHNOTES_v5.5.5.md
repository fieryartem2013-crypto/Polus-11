## 🔧 БАГ 1: «RebuildJobs nil» (F4 не открывался)
Причина: в старом UI `RebuildCats` вызывал `RebuildJobs`, объявленный
ПОЗЖЕ — в Lua это компилируется как ГЛОБАЛЬНАЯ → nil → краш при клике.
Исправлено: функции объявлены в правильном порядке
(`local RebuildCats, RebuildJobs` заранее). Плюс тело каждого билдера
обёрнуто в pcall — UI больше НИКОГДА не падает.

## 🔧 БАГ 2: «util.DropToFloor nil» (грязь и НПС падали при спавне)
Причина: в GMod НЕТ функции util.DropToFloor — правильно ent:DropToFloor().
Весь проект зовёт util.DropToFloor(self) → краш.
Исправлено новым файлом `p11_sv_dropfix_v555.lua`: доопределяем
util.DropToFloor глобально → чинит ВСЕ энтити сразу.
