# 🔒 ЗАТ — ЗАКРЫТЫЙ АЛЬФА-ТЕСТ «ПОЛЮС-11» (v3.3)
Дата: 05.08.2026. Сборка **3.3** (P11FW 1.5.0 + POLUS11 2.7).

## 0. ПЕРЕД ЗАПУСКОМ — 3 обязательных шага

1. **ПОМЕНЯТЬ СЕКРЕТНЫЙ КЛЮЧ ОСНОВАТЕЛЯ.**
   Файл: `gamemodes/polus/gamemode/modules/fw_sh_config.lua`,
   строка `FounderKey = "POLUS-GLAVA-1982-smeni-menya"` → впиши свой длинный ключ.
   Вход по ключу — в консоли клиента: `p11_access твой-ключ` → ранг «Глава Полюса-11» + superadmin.
2. **Закрыть сервер паролем**: в `garrysmod/cfg/server.cfg` раскомментируй `sv_password "..."`
   и раздай пароль тестерам в ЛС.
3. Поднять карту, в консоли сервера: `polus_status` — должно быть «модули 17/17»,
   энтити по нулям, версии 1.5.0/2.7/3.3 в логе стартапа.
