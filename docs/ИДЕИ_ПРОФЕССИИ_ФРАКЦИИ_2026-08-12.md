## ЧАСТЬ 2. НОВЫЕ ПОСТОЯННЫЕ ФРАКЦИИ

### 🏥 «ГРАЖДАНСКИЙ МЕДПЕРСОНАЛ» (новая, навсегда)
- **Лор:** гражданские врачи и медсёстры с «Большой Земли» (не военные).
- **Профы (4):** Главврач (лидер), Хирург (операции), Медсестра, Фельдшер.
- **Фишка:** НЕ воюют (нет оружия, кроме защиты), лечат ВСЕХ (и криминал),
  нейтральная зона в медблоке; НКВД их проверяет, но они «вне юрисдикции».
- **Модели:** медсёстры РККА (fem), гражданские стоковые.
- **Зачем:** даёт нейтральную РП-прослойку, конфликты «медик укрыл преступника».

### 🛠 «РЕМОНТНАЯ СЛУЖБА СТАНЦИИ» (новая, навсегда)
- **Лор:** техперсонал «Полюса»: чинят всё, знают все тоннели.
- **Профы (4):** Главный инженер (лидер), Электрик, Механик, Связист.
- **Фишка:** быстрее ремонт, доступ в технические тоннели (новые зоны),
  «живая карта» станции у главного инженера.
- **Зачем:** даёт «технарям» свою вертикаль и нужность.

### 🎖 «ВЕТЕРАНЫ ЗАТ» (новая, навсегда, для старожилов)
- **Лор:** выжившие с прошлых зимовок, «старики» станции.
- **Профы (3):** Старшина (лидер), Ветеран-разведчик, Ветеран-медик.
- **Фишка:** доступ только по стажу (1000+ минут), авторитет, особые
  шевроны/плашки, советы новичкам.
- **Зачем:** цель для старых игроков, «элита» без доната.

## ЧАСТЬ 3. ВРЕМЕННЫЕ ФРАКЦИИ (арки на 3–7 дней)

### 🇺🇸 «АМЕРИКАНСКАЯ ЭКСПЕДИЦИЯ» (арка 3–5 дней)
- **Лор:** Вашингтон «обеспокоен» — инспекционная группа под видом метеорологов.
- **Профы (5):** Руководитель, Связист, Медик, Охранник (морпех), Аналитик.
- **Фишка:** гостевое крыло, доклады в «Центр», дипломатический скандал
  если найдут ствол у «метеоролога»; НКВД следит.
- **Модели:** usarmy (уже есть — Орёл).

### 💀 «ВОЛНА МЁРТВЫХ» (ивент-осада 1–2 часа)
- **Лор:** Осовец поднимает волну — мертвецы идут на станцию.
- **Профы (для желающих):** «Мёртвый солдат» (модели undeadarmy).
- **Фишка:** игроки-зомби воскресают у ворот, цель — прорваться;
  люди держат периметр; по таймеру — финал и награда (рубли/стаж).

### 🦠 «КАРАНТИННЫЙ ОТРЯД» (ивент при вспышке)
- **Лор:** при 3+ заражённых прилетает отряд в гермокостюмах.
- **Профы (4):** Командир, Санитар, Охрана, Связист.
- **Фишка:** объявляют «КАРАНТИН», все обязаны пройти тест крови;
  забирают «образцы» (игроков) — РП-напряжение.

### 💼 «ПОЛЯРНЫЕ КОНТРАБАНДИСТЫ» (арка неделя)
- **Лор:** подпольная сеть на станции.
- **Профы (4):** Главарь, Курьер, Скупщик, Связной.
- **Фишка:** свои тайники, «заказы» дефицита дороже ларька; НКВД ищет.

### 🔧 «РЕМОНТНАЯ БРИГАДА ЛЕНИНГРАДА» (арка 3 дня)
- **Лор:** гражданские специалисты чинят станцию.
- **Профы (5):** Бригадир, Электрик, Сантехник, Сварщик, Кладовщик.
- **Фишка:** не воюют, чинят минииграми, им платят; военные охраняют;
  «штатские что-то ищут?» — арка паранойи без выстрелов.

### 🌊 «ПОЛЯРНИКИ-СЕЗОННИКИ» (арка 4–5 дней, зимняя)
- **Лор:** «вахта» прибыла на сезон: рабочие, повара, водители.
- **Профы (5):** Старший вахты, Повар, Водитель снегохода, Разнорабочий, Кладовщик.
- **Фишка:** обычные люди (слабее военных), но их много; «сезонная» работа.

## ⚙️ ТЕХНИЧЕСКИ (как реализуем)
- Каждая профа = запись в `P11FW.CustomJobs` через НОВЫЙ файл
  (autorun/server) — клиенты получат через JobsSync (проверено на профах
  НКВД/Унтер-СС).
- Каждая фракция = категория (RegisterCustomFactions) + свои профы +
  точки спавна (p11_arrival).
- Модели — из имеющихся (hts/comradebear, usarmy, сток) — паки не нужны.
- Включить/выключить: файл в autorun (положил = работает, убрал = нет).
- Баланс: без OP, ХП/броня в рамках существующих (90–110 / 25–60).

*Документ-идеи. Реализация — по команде владельца, по одной, новыми файлами.*
