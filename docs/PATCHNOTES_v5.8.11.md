# 📋 ПАТЧ-НОУТ v5.8.11 — «МУЗЫКА: ПОИСК ПО ВСЕМ ПУТЯМ»
**Дата:** 16.08.2026 · **Сборка:** POLUS11_SERVER_v5.8.11.zip

> 📌 Старые файлы не тронуты, всё новое.

## 🔍 ПОЧЕМУ БЫЛО «ПАПКА ПУСТА»
Твоя догадка верна по сути: звуки лежали **только в папке гейммода**
(`gamemodes/darkrp/sound/...`), а **серверный file.Find НЕ видит папку
гейммода** — она не входит в "GAME" search path. Старые скрипты
искали `sound/polus11/music/*` → пусто. Имя гейммода (darkrp/polus)
на это не влияло — дело именно в папке.

## ✅ ЧТО ДЕЛАЕТ v5.8.11
1. **Добавляет папку активного гейммода в search path**
   (`file.AddToSearchPath`) — теперь видны и звуки гейммода.
2. **Ищет звуки по ВСЕМ путям**:
   - `sound/**` (рекурсивно вся папка звуков);
   - `sound/polus11/music/*`;
   - `gamemodes/<гейммод>/sound/**`.
   Файл найдётся, **где бы его ни положили** (в пределах sound/).
3. **Раздаёт все найденные файлы клиентам** (resource.AddFile).
4. `polus_ost_1` — главный трек (повтор по кругу, автовключение,
   каждому заходящему).
5. **ДИАГНОСТИКА `p11_musicpath`** (админ): покажет, какие пути
   искали, что нашли, где polus_ost_1, что играет у игроков.

## ⚠️ УСТАНОВКА

2. Скопируй новую `garrysmod/` ЦЕЛИКОМ.
3. Кинь `polus_ost_1.mp3` в `garrysmod/sound/polus11/music/`.
4. Перезапусти сервер. Клиентам — перезапустить игру + удалить cache/.
