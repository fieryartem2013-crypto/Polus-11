# 📋 ПАТЧ-НОУТ v5.5.2 — «МАСТЕР UI (ФИКС ПОРЯДКА ЗАГРУЗКИ)»
**Дата:** 12.08.2026 · **Сборка:** POLUS11_SERVER_v5.5.2.zip

> 📌 Правило соблюдено: старые файлы не тронуты, всё новое в lua/autorun/.

## 🔧 ГЛАВНЫЙ ФИКС: ПОЧЕМУ НЕ БЫЛО ВИДНО ИЗМЕНЕНИЙ
Раньше переопределения UI лежали в `lua/autorun/client/`, а они грузятся
**ДО гейммода** → гейммод затирал мои функции обратно. Теперь ВСЁ
переопределяется **ПОСЛЕ загрузки гейммода** через хук
`PostGamemodeLoaded` + `InitPostEntity` + таймеры (0/1/2 сек) —
изменения реально видны.

## 🎨 НОВЫЙ МАСТЕР-СТИЛЬ (применён после гейммода)
- Палитра «красное знамя / золото / сталь / лёд» (P11UI.C) — перекрашены
  все окна на P11UI (F1-справка, онбординг).
- Улучшенный P11UI.Frame: градиент фона, знамя-шапка, свечение заголовка.
- Derma-патчи: DButton (красное наведение), DScrollPanel (золотой бар) —
  подкрашивают админку, ларёк, терминал, торговлю и др.

## 💼 НОВОЕ F4 (после гейммода)
- Категории-вкладки слева (с красным акцентом).
- Карточки проф: цвет фракции, градиент при наведении, статус-полоса,
  требования (🔒/💎/⏱/🎖/⭐/✖).
- Кнопка ВЗЯТЬ (логика прежняя).
- Анимация появления окна (плавный выезд + прозрачность).

## 🎛 НОВОЕ C-МЕНЮ (после гейммода)
- «ПУЛЬТ СМЕНЫ»: знамя-шапка, золотые секции, карточки-кнопки с
  подписями и градиентом при наведении, свечение заголовка.
- Все действия сохранены (анкета/обмен/F4/помощь/руки/внешность/
  инвентарь/заявка/древо/операции/маяки/расставить/админка/ранги/вайтлист).

## ⌨️ НОВЫЙ STRINGREQUEST — «советский» диалог ввода (знамя, ПРИНЯТЬ/ОТМЕНА).
