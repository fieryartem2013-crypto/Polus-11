# 📋 ПАТЧ-НОУТ v5.7.8 — «КРАСОТА: ИНТРО + МЕНЮ»
**Дата:** 15.08.2026 · **Сборка:** POLUS11_SERVER_v5.7.8.zip

> 📌 Правило соблюдено: старые файлы не тронуты, всё новое (энтити `polus_p11_menuv2` + спавнер).

## ✨ 1) МИНИ-ИНТРО В СТИЛЕ ХЕЛИСА
Длинное киношное интро заменено на короткое чистое (как в Хелисе):
- тёмный градиент, лёгкий снег, виньетка;
- **эмблема** (кольца радара + золотая звезда, вращается);
- заголовок **«ПОЛЮС-11»** с разрядкой, растущая линия, подзаголовок
  «ИССЛЕДОВАТЕЛЬСКАЯ СТАНЦИЯ · АНТАРКТИДА · ЗИМА 1982»;
- сегменты-прогрессбар снизу + **«НАЖМИТЕ, ЧТОБЫ ПРОДОЛЖИТЬ»**;
- пропуск — клик/любая клавиша, авто-закрытие через ~14 сек;
- уважает `p11_intro 0` (отключить), ручной повтор — `p11_intro_show`;
- пока идёт — анкета персонажа ждёт (как раньше).

## 👤 2) НОВОЕ МЕНЮ ПЕРСОНАЖА «ЛИЧНОЕ ДЕЛО БОЙЦА»
Полностью перерисовано:
- **слева** — живой аватар (модель игрока) + предпросмотр позывного
  и описания (обновляется прямо при наборе);
- **справа** — поля «ПОЗЫВНОЙ» и «ОПИСАНИЕ» с живыми счётчиками;
- стеклянный фон, эмблема-радар в шапке, золотая кнопка
  «ЗАПИСАТЬ В ДЕЛО» с уголками, ESC — закрыть;
- логика и пакет `P11_CharSave` те же (3–32 / до 140 знаков).

## 🎛 3) ПОЛИРОВКА С-МЕНЮ «ПУЛЬТ СМЕНЫ»
Поверх штатного меню (файл `p11_cl_cmenu.lua` НЕ тронут):
- стекло + градиент + едва заметная сетка, blur-фон;
- живая эмблема-радар в шапке, кошелёк с пульсацией;
- **все кнопки перерисованы**: ячейка-иконка, плавная подсветка
  при наведении, стрелка «›», тултип с описанием, серые — без прав;
- секции с аккуратной верхней гранью, уголки рамки.
