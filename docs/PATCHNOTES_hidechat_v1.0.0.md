# Патч-ноут: HIDE CHAT v1.0.0 (аддон)

**Дата:** 2026-08-14
**Тип:** новый отдельный аддон (не входит в сборку POLUS11_SERVER)

## Что сделано
Новый аддон **hidechat**: чат скрыт по умолчанию у каждого игрока,
показывается по нажатию **Y** (и **U** — командный чат) как тумблер.
Состояние хранится на сервере по SteamID64 и переживает переподключение
и рестарт сервера (файл `data/hidechat.json`).

## Структура аддона (только НОВЫЕ файлы, гейммод не тронут)
```
garrysmod/addons/hidechat/
├── README_УСТАНОВКА.txt
└── lua/
    ├── autorun/server/hidechat.lua          — сервер: состояние, net, сохранение + спавн энтити
    └── entities/polus_p11_hidechat/
        ├── shared.lua                       — описание энтити (point, не спавнится вручную)
        ├── init.lua                         — служебная «пустышка» (курьер cl_init)
        └── cl_init.lua                      — клиент: Y/U тумблер, Enter, блокировка вывода
```

## Почему клиентская часть в cl_init энтити
На сервере `sv_allowcslua 0` → файлы `lua/autorun/client` до клиентов
не доходят. Файлы энтити (cl_init.lua) раздаются всем игрокам ВСЕГДА.
Сервер спавнит невидимую энтити под картой `Vector(0,0,-20000)`
(паттерн fixboot / infoboot / f4boot — проверен на бою).

## Сетевые каналы (уникальные)
- `HideChat_Toggle` — клиент → сервер (переключить)
- `HideChat_State` — сервер → клиент (новое состояние, bool)

## Логика
- По умолчанию чат скрыт: `showChat = false`.
- Y/U → `PlayerBindPress` ловит бинды `say`/`say_team`, шлёт `Toggle`,
  возвращает `true` (блокирует ванильное открытие поля ввода).
- Пока игрок печатает (`chat.IsChatInputActive`) — тумблер не срабатывает.
- Enter → `chat.Open()` (когда чат показан).
- `ChatText` возвращает `true`, если чат скрыт (сообщения не выводятся).
- `HUDShouldDraw("CHudChat")` → `false`, если скрыт.
- `PlayerInitialSpawn` → сервер шлёт текущее состояние игроку.
- `PlayerDisconnected` → сохранение в `data/hidechat.json`.

## Установка
Распаковать папку `hidechat` в `garrysmod/addons/`, перезапустить сервер.
