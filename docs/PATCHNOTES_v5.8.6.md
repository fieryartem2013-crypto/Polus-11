# 📋 ПАТЧ-НОУТ v5.8.6 — «МУЗЫКА ВНУТРИ ГЕЙММОДА (ЭМБИЕНТ)»
**Дата:** 15.08.2026 · **Сборка:** POLUS11_SERVER_v5.8.6.zip

> 📌 Старые файлы не тронуты, всё новое.

## 🎵 ЧТО ИЗМЕНИЛОСЬ (по заявке «музыка в папке самого гейммода»)
Раньше звуки лежали в общей `garrysmod/sound/`, а скрипт — в
`garrysmod/lua/autorun/`. Теперь **всё внутри гейммода**
(`garrysmod/gamemodes/darkrp/`) — переносится вместе с ним:

| Что | Куда |
|---|---|
| музыка | `gamemodes/darkrp/sound/polus11/music/*.mp3` |
| скрипт скачивания + плеер | `gamemodes/darkrp/entities/entities/polus_p11_musicbg/` |

## 🎼 1) ФОНОВАЯ МУЗЫКА (ЭМБИЕНТ), НЕ ИНТРО
- включается **сама** через ~6 сек после старта сервера / смены карты;
- играет **по кругу** (loop, как фон станции);
- **каждому заходящему** — трек автоматически через 3 сек;
- громко (1.0 по умолчанию).

## 📥 2) СКАЧИВАНИЕ У КЛИЕНТОВ
Скрипт в `init.lua` энтити сам находит все файлы в
`sound/polus11/music/` гейммода и раздаёт их клиентам через
`resource.AddFile` — игроки качают при заходе, один раз, дальше кэш.
Файл `polus_ost_1.mp3` (если положишь) — автоматически станет
главным треком.

## 🎛 КОМАНДЫ (админ)
| Команда | Что делает |
|---|---|
| `!музыка` | список + что играет |
| `!музыка 2` / `!музыка polus_ost_1` | сменить трек |
| `!музыка стоп` / `!музстоп` | остановить |
| `!музгром 1.0` | громкость 0..1 (по умолчанию 1.0) |
| `!музцикл 1` / `!музцикл 0` | повтор вкл / выкл (по умолчанию ВКЛ) |

## 📦 ФАЙЛЫ (все новые, внутри гейммода)
| Файл | Роль |
|---|---|
| `gamemodes/darkrp/entities/entities/polus_p11_musicbg/init.lua` | сервер: скачивание, автозапуск, команды |
| `gamemodes/darkrp/entities/entities/polus_p11_musicbg/cl_init.lua` | клиент: плеер (loop) + индикатор |
| `gamemodes/darkrp/entities/entities/polus_p11_musicbg/shared.lua` | описание энтити |
| `gamemodes/darkrp/sound/polus11/music/*.wav` | демо-треки (полярный маяк, сирена) |
| `gamemodes/darkrp/sound/polus11/music/README_*.txt` | как добавить трек |

Скрипт грузится автоматически при старте гейммода (init.lua энтити) —
**init.lua гейммода не трогали**. Обработчик команд ставится
последним (таймеры до 48 сек) — активным остаётся именно этот.

## ⚠️ УСТАНОВКА
1. Удали на сервере папки `garrysmod/gamemodes/darkrp/` и `garrysmod/lua/autorun/`.
2. Скопируй новую `garrysmod/` ЦЕЛИКОМ.
3. Перезапусти сервер. Клиентам — перезапустить игру + удалить cache/.

## ПРОВЕРКА
- После рестарта через ~6 сек фоновая музыка играет сама (по кругу).
- Новый игрок заходит — через 3 сек слышит ту же музыку (скачал при заходе).
- `!музыка` — список; `!музстоп` — тишина; `!музыка 1` — снова.
