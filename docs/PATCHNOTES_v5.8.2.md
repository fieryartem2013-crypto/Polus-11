## 🎵 1) МУЗЫКА СТАНЦИИ (с авто-скачиванием у игроков)
Сервер раздаёт звуки всем клиентам **при заходе** (resource.AddFile):
игрок один раз качает трек, дальше он у него в кэше.

### Как добавить свой трек
1. Кинь `.mp3` в `garrysmod/sound/polus11/music/` (название латиницей,
   без пробелов: `sovetskiy_vals.mp3`).
2. Перезапусти сервер — сервер **сам найдёт файл**, раздаст его
   всем игрокам и добавит в список. Никакой правки кода не нужно.

### Команды (админ / суперадмин)
| Команда | Что делает |
|---|---|
| `!музыка` | список треков + что играет сейчас |
| `!музыка 2` | играть трек №2 всем |
| `!музыка стоп` / `!музстоп` | остановить |
| `!музгром 0.6` | громкость 0..1 (по умолчанию 0.6) |

Играет у каждого на клиенте (станционное радио), внизу справа —
индикатор «♪ МУЗЫКА СТАНЦИИ: <трек>» с пульсацией.
