# 0️⃣ ПОЛЮС FRAMEWORK (P11FW) — фреймворк сервера ⭐ ГЛАВНОЕ

**Замена DarkRP для станции.** Собственные профессии, своё F4-меню, NPC-кадровик. Без него polus11 работает как раньше (sandbox), с ним — все механики привязаны к должностям.

## Что даёт
- 7 должностей из ТЗ (гварнизон + научный персонал) + «Новобранец»
- F4 — своё меню должностей: описание, модель-превью, лимит мест, «Занять должность»
- NPC-кадровик (по E — то же меню), сохраняется на карту
- HUD должности + должность под ником у игроков
- polus11 читает профы: тест крови только учёным, огнемёт заправляют инженер/учёный

## Игроку
| Действие | Как |
|---|---|
| Открыть меню должностей | **F4** или чат `!работа` / `!job` / `!профа` |
| Взять должность | кнопка «ЗАНЯТЬ ДОЛЖНОСТЬ» в F4 или E по кадровику |
| Вариант внешности | кнопка «Внешность» под моделью (если вариантов >1) |
| Уволиться | кнопка в F4 справа внизу |

## Админу
| Команда | Действие |
|---|---|
| **`p11fw_admin` / `!фвадмин`** | **АДМИН-МЕНЮ**: игроки + наказания, редактор должностей, утилиты станции |
| `!нпс` / `!нпс убрать` | поставить/удалить кадровика |
| `polus_fw_setjob <ник> <jobId>` | выдать должность в обход лимита (jobId: recruit, guard, officer, cook, lab, virologist, engineer + кастомные) |
| `polus_fw_demote <ник>` | уволить в новобранцы |
| `polus_fw_jobs` | штат станции в консоль |
| `polus_fw_arrest/slavery/ban <ник> <мин> [причина]` | наказания консолью |
| `polus_fw_free` / `polus_fw_unban <sid64>` | освободить/разбанить |
| `polus_fw_setspawn` / `polus_fw_setjail` | точки спавна/ареста (или кнопками в админке) |

## 🛠 Админ-меню (v1.2) — что где
- **ИГРОКИ**: выбрал игрока → срок + причина → **АРЕСТ** (камера, заморозка, разоружён, таймер), **РАБСТВО** (без оружия/должности, не поднимает оружие), **БАН** (кик через 4 сек, вход закрыт) • ОСВОБОДИТЬ • УВОЛИТЬ • выдать должность выпадайкой
- **ДОЛЖНОСТИ**: список (встроенные/КАСТОМ) → форма: имя, категория, RGB-цвет, лимит, модели («+ МОЯ МОДЕЛЬ» добавляет твою), оружие («+ ОРУЖИЕ В РУКАХ» добавляет класс текущего оружия), описание → **СОЗДАТЬ** — должность сразу в F4 у всех, **сохраняется навсегда**; кастомные можно править и удалять
- **УТИЛИТЫ**: 🟢 спавн-поинт гарнизона, ⛓ камера ареста, 🧍 кадровик (создать/удалить), 📜 бан-лист со снятием бана

## 🔴 Наказанный видит
Сверху экрана чуть краснее + крупно: **ВЫ АРЕСТОВАНЫ** / **ВЫ В РАБСТВЕ** / **ВЫ ЗАБАНЕНЫ** + причина + осталось минут. Всё переживает смерть и реконнект (файлы в data/polus_framework/).

# 0️⃣.5️⃣ ПОЛЮС-11 v2.3 — АНТИ-СКУКА + РЕВОРК НЕЧТО (новое!)

## ✅ Задачи смены (анти-скука)
У каждой должности свои дела — виджет **«ЗАДАЧИ СМЕНЫ»** слева на экране, галочки по мере выполнения. Выполнил ВСЕ — объявление на станцию + бонус к здоровью:

| Профессия | Задачи |
|---|---|
| Инженер | долить солярку ×2, отремонтировать генератор, заправить огнемёт, 5 мин без смерти |
| Лаборант | кровь ×3, тест крови, 5 мин без смерти |
| Вирусолог | кровь ×2, тест, **вскрытие трупа**, 5 мин без смерти |
| Охрана | 150 урона Нечто, доклады в рацию ×3, караул 10 мин |
| Офицер | арест нарушителя, **построение по сирене** (≥40% станции рядом), караул 10 мин |
| Повар | накормить **3 разных** людей пайком, бочка к генератору, камбуз жив 5 мин |
| Новобранец | взять должность, осмотреться 5 мин |

## 🔬 Новые инструменты экипажа
- **Скальпель** (вирусолог/лаборант): вскрытие трупа за 5 сек → точный вердикт по состоянию на момент смерти. Заражённый учёный жмёт **R — подделка результата**.
- **Химсвет** (у всех, ×2 со спавна): ЛКМ — бросить, горит 10 мин, зелёный свет в блэкаут.
- **Паёк** (повар): ЛКМ по человеку — +15 хп ему, задача кормить разных.
- **Сирена** (пульт ивент-мастера): «Общее построение» — офицер собирает станцию.

## 🧟 НЕЧТО 2.0 — реворк
- **КРИК УЖАСА** `!крик`: все люди рядом — отброс, тряска экрана, паника (КД 45 сек)
- **НОВЫЙ КЛАСС «Поглотитель»**: танк — 170 хп и тяжёлый удар 80; ПКМ — смоляной пут сковывает человека на 4 сек
- **НОВЫЙ КЛАСС «Споровик»**: ПКМ — споровое облако (15 сек): люди внутри копят «дозу спор» → на 100 заражаются ТИХО; R — разорваться облаком ценой 60 хп. Люди видят на HUD «СПОРЫ: %»... нет, они видят только внешние признаки — заражение скрытое!
- **Смена формы**: `!форма поглотитель / споровик / имитатор / разделённый` (КД 60 сек)
- **Босс усилен**: рык-волна отбрасывает всех людей каждые 14 сек

## 😱 Стресс-эффекты
Смотришь на форму монстра вблизи — темнеют края экрана, тряска, тяжёлое дыхание. Если закричало совсем близко — «ТЫ ВИДИШЬ ЕГО».

# 1️⃣ PROF_NPC — «NPC Профессий» (требует DarkRP) ⚠️ УСТАРЕЛ — заменён ПОЛЮС FRAMEWORK

## Что это
НПС, у которых игроки берут профессии кнопкой «Устроиться». Меню F4 заблокировано — работу выдают только НПС. У каждого НПС своя модель и свой список профессий. Настраивается админом прямо в игре.

## Команды (админ)
| Команда | Где | Действие |
|---|---|---|
| `!profnpc` / `!npcjob` / `!нпс` | чат | создать НПС там, куда смотришь |
| `profnpc_create` | консоль | то же самое |
| `profnpc_remove` | консоль | удалить НПС (смотреть на него) |

## Кнопки в игре
| Кнопка | Что делает |
|---|---|
| **E** по НПС | меню профессий: батьки, название, зарплата, занятые слоты, описание, кнопка «Устроиться» |
| «Устроиться» | мгновенная смена профессии (согласно конфигу: лимит слотов, бан, customCheck) |
| «НАСТРОЙКИ НПС (админ)» | **только админы**: имя над головой, модель (путь/пресеты/«Модель из прицела»), галочки профессий (сортировка по категориям), сохранить, удалить НПС |
| «+ Создать НПС» | создать ещё одного (кнопка в меню админа) |

## Что работает «под капотом»
- НПС сохраняются на карте: `data/profnpc/<карта>.json` (переживают рестарт и очистку)
- 3D2D-надпись над головой с именем и подсказкой
- Блокировка F4: при нажатии — звук и сообщение в чат (раз в 10 сек)
- Антиспам смены профы (2 сек), проверка дистанции на сервере

## Конфиг `lua/profnpc/sh_config.lua`
`BlockF4` (выкл. блокировку F4), `F4Message`, `DefaultName/DefaultSubName` (текст над головой), `RespectJobMax`, `IgnoreVoteRequirement`, `IgnoreCustomCheck`, `UseDistance`, `IsAdmin`.

# 2️⃣ THING_SWEP — «Нечто» (3 варианта оружия)

## Что это
Оружие-монстр: убиваешь когтями — облик жертвы попадает в коллекцию маскировок. Можно принять вид любого убитого игрока (модель, скин, бодигруппы, цвет). Работает в любой мод (Sandbox/DarkRP/TTT).

## Оружие (спавн-меню Q → Оружие → «Нечто»)
| Название | Урон | Темп | Особенность |
|---|---|---|---|
| **Нечто** | 40 | 0.8 сек | +25 HP за убийство |
| **Нечто [Ядовитое]** | 22 | 0.9 сек | яд: 4 урона × 6 сек + зелёная кайма на экране жертвы |
| **Нечто [Быстрое]** | 20 | 0.32 сек | скорость бега ×1.5 пока в руках |

## Управление
| Кнопка | Действие |
|---|---|
| **ЛКМ** | атака когтями (кровь, отброс, порезы на стенах); уже убитое = маска в коллекцию |
| **R** | меню масок: список ников убитых → клик = принять облик |
| **ПКМ** | снять маскировку (с рыком) / рык, если маски нет |

## Что работает
- Коллекция масок: до 15 штук, новые сверху
- Атака **снимает маскировку** — Нечто раскрывает себя (отключается `AttackBreaksDisguise = false`)
- HUD слева внизу: «ВЫ — НЕЧТО» / «ОБЛИК: ник» + счётчик масок
- Уведомления при сборе маски: «Собрана маскировка: ник (всего: N)»
- Яд стакается заново при повторном ударе; очищается при смерти жертвы

## Конфиг `lua/thing/sh_config.lua`
`AdminOnly`, `MaxDisguises`, `AttackBreaksDisguise`, `ClearDisguisesOnDeath`, параметры каждого варианта (`Damage/Delay/Range/Knockback/HealOnKill/Poison/SpeedMul`).

# 3️⃣ POLUS-11 — станция «The Thing RP»

## Модули: ядро заражения + тест крови + генератор + огнемёт + классы + пульт + рации

## 🧬 ЗАРАЖЕНИЕ (автоматика)
- **Пациент-ноль**: рандом из пульта или вручную
- **Инкубация**: 150–280 сек БЕЗ каких-либо признаков
- **Звуки-подсказки**: раз в 45–90 сек рядом с носителем тихий «хруст» (слышат окружающие)
- **Активация**: красная рамка + «ЧТО-ТО ВНУТРИ ПРОСНУЛОСЬ» + авто-выдача `НЕЧТО: Имитатор`
- **Улей**: активные заражённые видят над своими красное «НЕЧТО» на расстоянии
- **Защита Нечто**: пули ×0.35, огонь ×3; в темноте +25% скорости и реген 3 HP/2сек

## 🩸 ТЕСТ КРОВИ
| Предмет | Как работает |
|---|---|
| **Шприц** (оружие) | ЛКМ в упор по игроку → колба в руке с именем донора. Кулдауны: 6 сек глобал, 30 сек на одного донора |
| **Колба** (энтити) | физический предмет, несёт метку «Кровь: ник». R у шприца = выбросить |
| **Лабораторный стол** (энтити) | принеси колбу, нажми E → 4 сек нагрева |
| **Результат** | НЕЧТО: колба ВИЗЖИТ, прыгает, зелёный пар. Человек: слабый пар |
| **Секретность** | текст результата видит ТОЛЬКО тестирующий |
| **Подмена** | если тестирующий сам НЕЧТО — всплывает окно «ПОДМЕНИТЬ РЕЗУЛЬТАТ / ПОКАЗАТЬ ПРАВДУ» |

## ⚡ ГЕНЕРАТОР И ТОПЛИВО
| Элемент | Данные |
|---|---|
| **Дизель-генератор** (энтити) | старт 600 сек топлива, максимум 900; мерцание искр < 120 сек; 3D2D-табло со статусом |
| **Бочка с топливом** (энтити) | поднести к генератору, нажать E = +600 сек |
| **Блэкаут** | пустой/сломанный генератор (если нет других) = ТЬМА на весь рендер + надпись «АВАРИЯ ЭНЕРГОСИСТЕМЫ» |
| **Саботаж** | НЕЧТО удерживает E 8 сек → генератор сгорает, искры, взрыв-звук |
| **Ремонт** | любой игрок удерживает E 6 сек по сломанному |
| **Урон пулями** | 600 HP генератора — можно расстрелять |
| **Заправка огнемёта** | взять огнемёт в руки, E по генератору: 3 сек топлива генератора = 1 ед огнемёта |

## 🔥 ОГНЕМЁТ (оружие)
- ЛКМ = струя (частицы + динамический свет), конус ~320 ед, поджог 3 сек, 10 DPS
- Емкость 200 ед, спавнится наполовину; полоса топлива на HUD
- Отдельный звук пустого бака + надпись «НЕТ ТОПЛИВА»

## 🕷 КЛАССЫ НЕЧТО (оружие)

### НЕЧТО: Имитатор (AdminOnly)
| Кнопка | Действие |
|---|---|
| ЛКМ | когти 40 ур (55 из раскрытой формы); атака **раскрывает тварь**: модель меняется на монстра, на 20 сек |
| ПКМ | **тихий укол** (дистанция 110): заражает цель БЕЗ сообщения жертве, лёгкий щелчок; кулдаун 90 сек |
| **R по трупу** | 🩸 **СЪЕСТЬ ТРУП = полное поглощение личности**: копируются модель, скин, бодигруппы, цвета, **ник** (в чат для не-DarkRP) и **DarkRP-имя** (таб/чат/над головой). Труп исчезает со звуком пожирания, +25 HP. Подсказка «[R] — СЪЕСТЬ ТРУП» при наведении |
| R без трупа (в чужом облике) | вернуть СВОЮ личность (не раньше чем через 5 сек) |
| R без трупа (свой облик) | раскрыть форму монстра на 20 сек / спрятать обратно |

Внизу экрана видно свою украденную личность: `ЛИЧНОСТЬ: ник | R — вернуть себя`. В лог станции пишется: `ПОГЛОЩЕНИЕ ЛИЧНОСТИ: ... съел труп ...`

### НЕЧТО: Разделённый
| Кнопка | Действие |
|---|---|
| ЛКМ | быстрые когти 18 ур, темп 0.28 сек |
| ПКМ | **кислотный плевок**: снаряд, сплэш 90 ед, 22 ур, ядовито-зелёный; кулдаун 2.2 сек |
| R | **паучья форма**: модель торса-паука, скорость ×1.6, прыжок 300; лазание = прыгай чтобы упереться в стену (толкает вверх); минимум 10 сек в форме |

## 👹 БОСС «ТВАРЬ ИЗ ТЕПЛИЦЫ»
Гигантский зомби (масштаб ×2.2, 900 HP). Каждые 9 сек выпускает малых зомби (макс. 4 на поле). Пули ×0.5, **огонь ×5**. Спавн с пульта туда, куда смотрит ивент-мастер. Требует навигационную сетку на карте.

## 📻 РАЦИИ (оружие)

## 💬 Чат-команды POLUS-11
`!пульт`, `!pult`, `!panel` — пульт • `/r текст` — рация

## ⚙ Всё настраивается в `lua/polus11/sh_config.lua`
Инкубация (150–280), хруст (45–90), защита от пуль/огня (0.35/3.0), топливо (600/900/120), саботаж/ремонт (8/6 сек), огнемёт (200/320/10 ДПС), тест крови (4 сек, 30 сек), помехи рации (0.10/0.50), DarkRP-профессии учёных и инженеров (`RestrictJobs`), список фаз.

## 📋 Лог станции
Всё пишется в консоль сервера с префиксом `[POLUS-11]`: заражения, активации, тесты крови (с пометкой о подмене!), саботаж, рации, боссы + дублируется в пульт.
