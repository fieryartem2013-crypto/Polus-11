# 📊 ПОЛНЫЙ РАЗБОР СБОРКИ — ПОЛЮС-11 v5.8.27

**Дата:** 23.08.2026  
**Сборка сейчас:** `POLUS11_SERVER_v5.8.27`  
**Следующий пакет:** `POLUS11_SERVER_v5.8.28`  
**Правило работы:** любой фикс/фича = **новый файл** (`lua/autorun/...` или новая энтити). Старые `p11_*` / `fw_*` / `init.lua` / `cl_init.lua` **не трогаем**.

> Это не «ещё одна идея ради идей». Это карта того, что реально лежит в репозитории, что сломано, что дублируется, и в каком порядке чинить.

## 0. ВЕРДИКТ В 8 СТРОКАХ

1. Это **не DarkRP-сервер с аддонами**, а свой гейммод `polus` (P11FW + POLUS-11) на Sandbox-базе, с опциональной совместимостью с DarkRP.
2. Контента **слишком много для текущего онлайна**: 440+ файлов, ~57 проф, 9 фракций, 4 поколения Нечто, 3 поколения чата, ~36 autorun-патчей поверх ядра.
3. Сборка **живёт слоями**: каждая версия кладёт новый файл поверх старого. Откат лёгкий, но runtime = лотерея «чей хук последний».
4. Есть **реальные дыры**, не «хотелки»: клиент не грузит СБОР и БАТЛПАСС; версия в игре застыла на `5.8.17`; ключ Главы лежит в shared; `!профа` может любой.
5. Тема («Нечто», 1982, полярная станция) — главное преимущество. Его уже размывают ООН/ГОК, Альфа Тера, операции СССР/США, криминал, гараж LVS.
6. Рынок не простит «ещё 10 систем». Нужны **стабильный круг смены** и **одна понятная фантазия**.
7. Правило «всегда новый файл» спасает от смерти сборки, но **уже само стало источником багов** (дубли net, 7 копий музыки, обёртки PlayerSay).
8. Следующие пакеты должны быть **хирургическими**: один баг / одна система / один новый файл. Не «ещё фракция».

## 1. ЧТО ЭТО ЗА СЕРВЕР (по факту кода)

| Слой | Что это | Где |
|---|---|---|
| Ядро гейммода | `gamemode polus` (не DarkRP) | `garrysmod/gamemodes/polus/` |
| Фреймворк должностей | P11FW: профы, фракции, ранги, вайтлист, F4, админка, наказания | `fw_*.lua` |
| Игровой слой | POLUS-11: Нечто, холод, экономика, лут, рация, задачи | `p11_*.lua` |
| Патчи «не трогать ядро» | autorun после гейммода + энтити-«бутстрапы» | `lua/autorun/` + `entities/polus_p11_*` |
| Чат | BonChat (усыплён) + свой «СВЯЗЬ» (`p11_cl_pchat`) + роутер `p11_sv_chat` | 3 поколения |
| Конфиг хоста | hostname ЗАТ, пароля нет, `sv_cheats 0`, `sv_allowcslua 0` | `cfg/server.cfg` |

**Важная путаница установки.** Патчноуты v5.8.x пишут: *«удали `garrysmod/gamemodes/darkrp/`»*. В репозитории гейммод называется **`polus`**, `server.cfg` запускает `gamemode polus`. Если на живом хосте лежит DarkRP с нашими модулями внутри — это **две разные карты мира**. Любая установка «скопируй garrysmod целиком» может положить не ту папку.

`POLUS_BUILD` в игре = **`"5.8.17"`** (последний `p11_sh_version_*.lua` в autorun/shared). Версии 5.8.18–5.8.27 **не объявлены**. Баннер при входе врёт.

## 2. КАРТА СИСТЕМ (что включено / что мертво)

### 2.1 Фракции и штат (сид)

| Фракция | Роль на станции | Замок | Комментарий |
|---|---|---|---|
| **РККА** | гарнизон, ядро RP | время + древо | слишком жирная ветка (генералы, лётчик, снабженец, 2 медсестры…) |
| **НКВД** | контрразведка, допросы | вайтлист | флагман темы; «чтение меток» уже вырезано — правильно |
| **Учёные / ЦНИИ** | кровь, вскрытия, крафт науки | время | стол «КРОВЬ-2» + подмена анализа = лучшая механика паранойи |
| **Персонал** | повар / уборщик / грузчик / техник / медик / водитель | открыто | кормит смену, но новичок тонет в F4 |
| **Криминал** | курьер → барыга / взломщик / главарь | древо, не вайтлист | ок как тень станции, не как вторая армия |
| **Красный Орёл (США/ЦРУ)** | шпионы 1982 | вайтлист (кроме связного) | лор держится; Velociraptor ломает эпоху |
| **ООН / ГОК** | 9 проф, современные стволы | частично WL | **ломает 1982 и «Антарктиду»** |
| **Альфа Тера** | 5 проф, личная фракция | весь WL | ещё одна армия на той же карте |
| **СССР/США (операция)** | ивент «РУБЕЖ» | cmdonly | нормально как *временный* ивент |
| **НЕЧТО** | скрыто, вакансия у кадровика | ивент | должно быть центром, а не одной вкладкой из десяти |

Лимит движка: **team index ≤ 255**. Уже роняли все профы (v5.8.26), базу сдвинули 200→140. Запас есть (~116 слотов), но **каждая новая фракция снова играет в эту лотерею**.

### 2.2 Нечто (ядро хоррора) — 4 поколения сразу

| Поколение | Файл | Статус |
|---|---|---|
| v1 заражение/инкубация | `p11_sv_infection` + `p11_sv_nechto` | жив |
| ЛИЧИНА 2.0 | `p11_sv_thingcore` | жив |
| ЛИЧИНА 3.0 | `p11_sv_thingkit` + `p11_cl_thingkit` | жив, подменяет API |
| КОРЕНЬ (до рестарта) | `p11_sv_thingroot` (последний в init) | жив |
| Разум жертвы | `p11_sv_thingmind` | жив (`!саботаж`) |
| Вакансия кадровика | `p11_sv_thingoffer` + 2 клиента (`offer` и `thingoffer`) | **двойной UI** |
| Мутации HUD | `p11_cl_mutations` + пульт kit | два HUD |
| Формы SWEP | imitator / split / brute / spore + босс | живы |
| Антидот / снятие | смерть/профа — конвары; кнопка изгнать; админ-пульт | 3 двери, игроки путаются |

**Проблема дизайна:** Нечто то «до рестарта», то «снимается смертью», то «кнопка изгнать». Канон фильма — *никто не знает и нельзя просто выйти*. Сейчас это то PvP-класс, то вакансия, то админ-ивент.

**Проблема безопасности темы:** `P11_Infected` / `P11_InfActive` / личина — `NW*`. Любой чит-меню читает «кто тварь» за секунду. Для ЗАТ «своих» ок. Для открытого онлайна — смерть паранойи.

### 2.3 Экономика и прогрессия (слишком много валют)

Одновременно живут:

- **₽ рубли** — кошелёк, ларёк, оклад, дежурства, контракты, штрафы, казна
- **ПФ (Полюс-Флюкс)** — донат
- **⏱ стаж / минуты** — допуск к профам
- **XP древа службы** 0..10 — РККА / учёные / криминал
- **Батлпасс 20 ур.** — клиент **не подключён в `cl_init.lua`**
- **Контракты часа + суточный наряд + стрик**
- **Задачи смены + терминал + ложные задачи Нечто**
- **Онбординг «первый день»**
- **Очки науки (RP учёных)**
- **Медали** — написаны, затем **вырезаны заглушкой v5.2.5**, файлы на диске

Игрок не понимает, *зачем вставать утром*. Пять прогрессий бьются за одно внимание.

**Дыра экономики:** дежурство платит `p11_dutywage` ₽/мин просто за NW-флаг поста. AFK на КПП = печатный станок. Смерть снимает пост, дисконнект тоже — но стоять в углу 3 часа можно.

### 2.4 Чат и голос — кладбище поколений

Живые:

1. Серверный роутер `p11_sv_chat` (`P11.ChatCore`) — каналы, радиусы, личина
2. Клиент «СВЯЗЬ» `p11_cl_pchat` (последний в cl_init — побеждает net)
3. Полоса каналов `p11_cl_chatsel` (писалась под BonChat)
4. BonChat целиком в гейммоде (усыплён, 19 файлов + emoji 200 КБ)
5. Старый `p11_cl_chat.lua` всё ещё **грузится**
6. Голос `p11_sv_voice` + рация `p11_sv_radio` + патч `p11_sv_radiofix_spawn_v581`
7. **39 хуков PlayerSay** + несколько обёрток `P11.ChatCore` (дежурства, `!профа`)
8. Музыка/радио: **один и тот же `P11.MusicCmd` перезаписывается 7 раз** (v582, v583, v584, v585, v589, v5811, v5812)

Отсюда вечная боль «чат не пишет / Enter мёртв / сообщения столбиком / техсообщения пропали». Каждый патч лечил симптом, не анатомию.

### 2.6 Станция (мир)

Живое: лутницы (еда/арм/мед/мил/тех/ящик/бочка/тайник), верстак, лабстол, кровь-2, буржуйка, кухня, сейф, снабжение, кадровик, ларёк, гараж, контрактник, кладмен, точки захвата, терминал рейда, наручники + караул, швабра/грязь, химсвет.

Вырезано, но файлы лежат: генератор (`p11_sv_nogen`), погода, рассудок, патрули, диспетчер, медали, ярмарка, hidechat, Осовец.

**Риск:** `OnEntityCreated` глушит генераторы. Старые place-JSON с генераторами будут молча исчезать — ок. Но свет «всегда горит» убивает хоррор. Тьма осталась только у пульта / `!саботаж`.

### 2.7 Админка и безопасность рангов

16 рангов User → Глава. Иерархия наказаний в целом здравая (не бить равных/выше).  
Блокеры:

- **`FounderKey` в `fw_sh_config.lua` (SHARED)** — любой клиент читает ключ `АрчиславКрутойПарень2013` и пишет `p11_access`. Это не секрет, это пароль в открытом виде.
- `P11FW.Config.Admin` принимает **ванильный `IsAdmin()` / `IsSuperAdmin()`**. На чужом хосте с ULX/SAM случайный admin-флаг = полный доступ к сборке.
- Античит v4.2: только rate-limit net + флаги скорости. **Нет проверки цены на части клиентских актов** (нужен точечный аудит `P11_InvAct`, `P11_DutyAct`, `P11_TreeAct`, казны). Автокиков нет — правильно для ЗАТ, мало для паблика.
- `!профа <текст>` (v5.8.14): **любой игрок** меняет `P11_JobName` в TAB и над головой. Нечто / шпион может назваться «Начальник НКВД» без вайтлиста.

### 2.8 Что клиент НЕ запускает (баги лоадера)

`init.lua` шлёт клиенту, но `cl_init.lua` **не include**:

| Файл | Что ломается |
|---|---|
| `p11_cl_sbor.lua` | экстренный сбор: баннер, маркер, итог переклички |
| `p11_cl_battlepass.lua` | F5 / окно пропуска |

Орфаны на диске (написаны, из лоадера вынуты): `board_v2`, `nametags_v2`, `medals_v2`, `chat_v2`, `duty` v1, `sanity`, `weather`, `raceweek`, фиксы v523/v524.

Это не «архив». Это мины: кто-то когда-нибудь снова include'ит оба поколения.

## 4. АРХИТЕКТУРНЫЙ ДОЛГ (почему «ещё фикс» опасен)

```
init.lua / cl_init.lua     ← ЗАМОРОЖЕНЫ правилом
        ↓
   ядро модулей 2026-08
        ↓
autorun v5.2.5 … v5.8.14   ← обёртки хуков, заглушки API
        ↓
энтити-boot (music, f4, hud, menu, ungoc, plates…)  ← клиентский код,
                                                      спрятанный в SENT
```

Плюсы правила: откат = удалить файл; ядро-сувенир целое.  
Минусы, которые уже стреляют:

1. **Нельзя починить лоадер** (сбор/батлпасс) без костыля-boot.
2. Нельзя выключить старый модуль — только переопределить глобалы/хуки позже.
3. Порядок autorun = алфавит (`zz_fixes` последним — это костыль, не дизайн).
4. Клиентские фиксы живут как невидимые энтити в `-20000` под картой. Cleanup/ошибка спавна = фикс умер, и никто не знает.
5. Документация (README 186 КБ changelog) **не читается**. Игрок/админ не знает, что включено *сегодня*.

**Предложение на будущее (не ломая правило):**  
завести *один* новый «диспетчер эпохи» `lua/autorun/server/p11_sv_epoch_v5828.lua` + клиентский близнец, который:

- ставит `POLUS_BUILD`
- `hook.Remove` известных мёртвых имён
- включает/выключает фичи таблицей `P11.Epoch = { medals=false, sbor=true, ... }`
- больше никаких семи копий музыки

Это не рефакторинг ядра. Это **пульт поверх слоёв**.

## 5. РАЗБОР ПО КРУГАМ ИГРЫ (что чувствует игрок)

### Новичок (0–30 мин)
Видит интро → анкету позывного → F4 на 50 карточек → не знает, куда идти.  
GPS/POI/онбординг/туториал/гайд есть, но **не собраны в одну нитку**.  
Нужен один сценарий: «ты новобранец РККА → подойди к кадровику → возьми паёк → дежурство 5 мин → услышь сирену».

### Середина смены
Холод, лут, наряды, ларёк, рация — мясо есть.  
Но нет давления: свет всегда горит, бури нет, Нечто раз в 15–30 мин вакансией, можно фармить дежурство.

### Нечто
Механики сильные (личина, документы, подмена крови, разум жертвы, когти 400 ХП).  
Слабое: метагейм TAB/NW, снятие по кнопке, четыре формы без обучения, HUD твари конфликтует с обычным (для этого и conscript'или `hudfix`).

### НКВД
Досье, улики, наручники, караул, штраф в казну — лучший «социальный» контент сборки.  
Не хватает: шаблона протокола, комнаты допроса как места (не только SWEP), награды за *обоснованный* арест, наказания за ложный.

### Админ
Пульт Нечто, казна, оповещения, операции, замок консоли — мощно.
