# 🚩 ПОЛЮС-11 — ИДЕИ: НОВЫЕ ВРЕМЕННЫЕ И ИВЕНТОВЫЕ ФРАКЦИИ
**Дата:** 12.08.2026 · **Статус:** идеи для банка (реализация по команде владельца)

> Что такое «временная/ивентовая фракция»: появляется на время сюжетной
> арки/ивента (от пары часов до недели), имеет свои профы/модели/задачи,
> потом убирается. Всё реализуется НОВЫМИ файлами, отключение — удалением
> строки (или файла). Обычные фракции не трогаем.

## Подробно по каждой

### 1. «Американская экспедиция» (ЦРУ/морпехи) — арка 3–5 дней 🇺🇸
- **Лор:** Вашингтон «обеспокоен советской программой» — присылает
  «инспекционную группу» под видом метеорологов.
- **Профы (4–5):** Руководитель группы (лидер, переговоры), Связист
  (рация с Центром), Медик экспедиции, Охранник (морпех), Аналитик
  (собирает данные).
- **Механики:** свои точки спавна (гостевое крыло), «доклады в Центр»
  (терминал), запрет на оружие кроме охраны (дипломатический скандал
  если найдут ствол у «метеоролога»).
- **Конфликт:** НКВД следит за ними (досье, обыски) — идеальная арка
  на недоверие.
- **Модели:** американские (usarmy уже есть в коде — отряд «Красный Орёл»).

### 2. «Волна мёртвых» — ивент-осада 1–2 часа 💀
- **Лор:** Крепость Осовец «поднимает» волну — мертвецы идут на станцию.
- **Фракция для ИГРОКОВ-ЗОМБИ:** желающие получают временную профу
  «Мёртвый солдат» (модели undeadarmy уже есть): воскресают у ворот,
  цель — прорваться внутрь.
- **Люди:** держат периметр, чинят баррикады, НКВД координирует.
- **Финал:** по таймеру волна откатывается, «победившая» сторона
  получает награду (рубли/стаж, не жетоны).
- **Плюс:** использует уже готовые модели и систему спавна.

### 3. «Карантинный отряд» — ивент при вспышке 🦠
- **Лор:** при 3+ заражённых «Большая Земля» присылает отряд в
  герметичных костюмах.
- **Профы:** Командир отряда, Санитар (проверяет кровь у ВСЕХ), Охрана
  (не пускает/не выпускает), Связист.
- **Механики:** объявляют «КАРАНТИН» (секции закрыты — барьеры),
  все обязаны пройти тест крови у отряда; Нечто в панике.
- **Конфликт:** отряд «забирает образцы» — игроков, которых считают
  заражёнными (РП-напряжение: а вдруг ошиблись?).
- **Финал:** отряд улетает через час, станция «очищена» (или нет).

### 4. «Полярные контрабандисты» — арка неделя 💼
- **Лор:** на станции просыпается подпольная сеть — свои люди у
  интендантов.
- **Профы:** Главарь (лидер), Курьер (носит товар), Скупщик (покупает
  краденое), Связной (договаривается).
- **Механики:** свои тайники (система stash уже есть), «заказы» —
  игроки заказывают у них дефицит (патроны/медицина) дороже ларька;
  НКВД ищет сеть.
- **Конфликт:** «крышует» ли кто-то из администрации? — РП-интрига.
- **Финал:** облава (ивент) или легализация.

### 5. «Ремонтная бригада Ленинграда» — арка 3 дня 🔧
- **Лор:** станции нужен ремонт — прибывают гражданские специалисты.
- **Профы:** Бригадир (лидер), Электрик, Сантехник, Сварщик, Кладовщик.
- **Механики:** их «дела» — чинка (переиспользовать миниигры), они НЕ
  воюют (нет оружия), им платят за работу; игроки-военные их охраняют.
- **Конфликт:** «штатские» что-то ищут? Кто-то из них пропал? — арка
  на паранойю без выстрелов.
- **Финал:** бригада уезжает, станция «отремонтирована» (новые энтити).

## 🔧 Как это технически (для реализации)
- Каждая фракция = **набор новых файлов**: сид-профы (CustomJobs через
  autorun), категория фракции (RegisterCustomFactions), точки спавна
  (p11_arrival), свои команды/задачи.
- Включается/выключается: файл в `lua/autorun/` — положил = работает,
  убрал = нет. Ничего в старых файлах не меняется.
- Модели: переиспользуем уже имеющиеся (usarmy, undeadarmy, nkvd,
  rkka) — паки не нужны.
- Каждая фракция — ОТДЕЛЬНАЯ арка, реализуем по одной, по команде.
