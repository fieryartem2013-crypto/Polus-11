# 📋 ПАТЧ-НОУТ v5.8.19 — «РЕПОРТЫ: НЕБЛОКИРУЮЩЕЕ УВЕДОМЛЕНИЕ»
**Дата:** 17.08.2026 · **Сборка:** POLUS11_SERVER_v5.8.19.zip

> 📌 Правка по заявке владельца (разрешение на правку файлов есть).

## 🐛 ПРОБЛЕМА
При новом репорте у админа **САМО открывалось полноценное окно-попап**
(`MakePopup()`), которое захватывало мышь и ввод. Админ в перестрелке
вылетал в окно и не мог стрелять, пока его закрывал — «может сдохнуть,
пока закрывает окно».

## ✅ ЧТО ИСПРАВЛЕНО (`p11_cl_reports.lua`)
1. **Авто-открытие окна ЗАМЕНЕНО на неблокирующую HUD-плашку**:
   - при новом репорте админ видит справа сверху аккуратную плашку
     «📨 НОВЫЙ РЕПОРТ» с текстом жалобы и подсказкой «/репорты —
     открыть окно»;
   - плашка рисуется в HUD — **НЕ захватывает мышь/ввод**: можно
     продолжать стрелять, двигаться, играть;
   - сама гаснет через ~16 сек (с плавным затуханием), звук остался;
2. **Окно — только по явной команде** (`/репорты` /reports !репорты
   !reports / `p11_reports`);
3. **Повторная команда закрывает окно** (toggle) + ESC тоже закрывает;
4. Тост в чат по-прежнему дублируется (видно даже без плашки).
