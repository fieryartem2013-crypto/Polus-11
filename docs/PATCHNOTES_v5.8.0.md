# 📋 ПАТЧ-НОУТ v5.8.0 — «СЕРВЕР ВО ВКЛАДКЕ DarkRP»
**Дата:** 15.08.2026 · **Сборка:** POLUS11_SERVER_v5.8.0.zip

> 📌 Lua-код гейммода НЕ тронут. Изменено только имя гейммода
> (папка + txt-описание) и server.cfg (gamemode + теги).

## 🎯 ЧТО СДЕЛАНО
Браузер серверов GMod показывает сервер во вкладке **«DarkRP»**
только если гейммод называется `darkrp` (папка `garrysmod/gamemodes/darkrp/`
+ `gamemode darkrp`). Раньше гейммод звался `polus` — сервер был
только в «Все». Теперь:

1. **Папка гейммода переименована:** `garrysmod/gamemodes/polus/` →
   `garrysmod/gamemodes/darkrp/` (содержимое то же, файлы не менялись).
2. **Описание гейммода:** `polus.txt` → `darkrp.txt` (первая строка
   `"polus"` → `"darkrp"`; заголовок остался «POLUS-11 RP»).
3. **server.cfg:** `gamemode polus` → `gamemode darkrp`
   + добавлено `sv_tags "darkrp,roleplay"` (для поиска/фильтров).

**Название в браузере останется «POLUS-11 RP»** (GM.Name не тронут),
но сервер появится в категории DarkRP — основной поток RP-игроков.

## ✅ ПРОВЕРЕНО
- В коде гейммода НЕТ жёстких путей `gamemodes/polus` — переименование
  папки безопасно, ничего не сломается.
- Все проверки имени гейммода в клиентских обёртках отсутствуют.
- Маркер версии: `p11_sh_version_v580.lua` (POLUS_BUILD = "5.8.0").

## ⚠️ УСТАНОВКА (ВАЖНО — иначе будет ДВА гейммода)
1. Удали на сервере папки:
   - `garrysmod/gamemodes/polus/` (старая, с прошлых сборок);
   - `garrysmod/gamemodes/darkrp/` (если вдруг осталась);
   - `garrysmod/lua/autorun/` (старый).
2. Скопируй новую `garrysmod/` из архива ЦЕЛИКОМ.
3. В `garrysmod/cfg/server.cfg` убедись, что стоит `gamemode darkrp`
   (в сборке уже так; если твой хостинг берёт гейммод из панели —
   поставь там `darkrp`).
4. Перезапусти сервер.

## ПРОВЕРКА
- Зайди в браузер серверов GMod → вкладка **DarkRP** → твой сервер там.
- В колонке «Игровой режим» будет DarkRP / POLUS-11 RP.
- Внутри всё работает как раньше (гейммод тот же, только имя).

## ↩️ ОТКАТ
Чтобы убрать из вкладки DarkRP: верни папку `gamemodes/darkrp` →
`gamemodes/polus` и `gamemode darkrp` → `gamemode polus` в server.cfg.
