## 1. 🔧 ПОЧИНЕНО: падение админ-панели (критический баг)

**Симптом:** при открытии админки (F4 → АДМИНКА / p11fw_admin) у любого админа ошибка:
```
[ERROR] fw_cl_admin.lua:2230: attempt to call a nil value
```
и панель не открывалась.

**Причина:** вкладка «КАЗНА» вызывала `DLabel:SetAutoWrapVertical(true)` —
метода с таким именем в GMod НЕ существует (правильно: `SetWrap` + `SetAutoStretchVertical`).

**Что сделано** (`fw_cl_admin.lua`):
- метод заменён на рабочие `SetWrap(true)` + `SetAutoStretchVertical(true)` — падение устранено;
- вкладка «КАЗНА» обёрнута в защиту `pcall` — будущая ошибка внутри неё больше НЕ роняет всю панель (в консоли появится `[POLUS][ERROR] вкладка КАЗНА: …`);
- запрос данных админки перенесён в начало сборки панели — даже если одна вкладка сломается, списки/ростер всё равно приедут.

## 2. 🎖 МЕДАЛИ: ПЕРЕДЕЛАНЫ С НУЛЯ (полностью, «не работали и не дорабатывались»)

По решению владельца система медалей **переписана заново** (`p11_sv_medals.lua`,
`p11_cl_medals.lua`) — чистая версия, без старых наслоений:

**Сервер:**
- реестр знаков, сейв `data/polus11/medals.json`, выдача/снятие;
- синк клиентам через **`net.WriteString(JSON)`** — тот же паттерн, что у
  рабочих проф/фракций (старый путь `WriteData+Compress` молча терялся);
- страховка: реестр **сам рассылается всем раз в 2 минуты**;
- автонаграды по счётчикам (50 тестов / 5000 урона / 10 лечек) + страховочный
  тик раз в 2 минуты;
- звено в цепи `TaskEvent` сохранено — батл-пасс и другие модули работают;
- `p11_medalgive <сид64|ник> <id>` — выдача с консоли Главы.

**Клиент:**
- приём реестра через простой `net.ReadString()` + разбор;
- API сохранён: `P11.MedalIds / MedalGlyphs / MedalColorOf / MedalCells /
  MedalTop / MedalScopeLocal / MedalAwardMenu / P11FW.MedalsTabBuild` —
  намики, TAB и админка работают без правок.

**Проверка:** выдать медаль → через пару секунд она появится над головой
(планка под рангом), в TAB (лента + счётчик) и в админке (вкладка МЕДАЛИ).
Старые выдачи подтянутся из `medals.json` сами.

## 3. 🛡 НОВОЕ: система «ДЕЖУРСТВА» (заявка владельца)

**НПС «Дежурный главы»** (`polus_p11_dutynpc` — Q → Энтити → ПОЛЮС-11, AdminOnly):

- **E по НПС** → меню поста → выбор локации:
  1. **КПП 2**
  2. **КПП · Приезжая часть**
  3. **Поверхность**
  4. **Комплекс за Сотрудником**
- Пока дежуришь — золотая плашка **«🛡 ДЕЖУРНЫЙ · <пост>» над головой, выше ника**, и пост в колонке должности в TAB;
- **Оклад +100₽/мин** (живой тюнинг: `p11_dutywage <0..1000>`);
- **Снятие:** кнопка в меню НПС, команда **`!снятьдежурство`** (или `!снятьпост`) — все команды станции через «!», как `!гараж`/`!крафт`/`!пульт`;
- Смерть или выход с сервера — пост снимается автоматически.

**Файлы:** `p11_sv_duty.lua`, `p11_cl_duty.lua`, `entities/entities/polus_p11_dutynpc/*` + подключение в `init.lua`/`cl_init.lua`.
