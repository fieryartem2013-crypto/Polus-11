## ✅ РЕШЕНИЕ v5.5.6: UI в энтити (не зависит от старых файлов)
Весь мастер-UI теперь в **энтити `polus_p11_uiboot`**:
- Файлы энтити — часть `gamemodes/polus/` — при установке они ТОЧНО
  попадают на сервер (ты заменяешь эту папку).
- Клиенты скачивают cl_init энтити АВТОМАТИЧЕСКИ при подключении
  (не зависит от lua/autorun и sv_allowcslua).
- cl_init энтити исполняется ПОСЛЕ гейммода → перебивает ЛЮБОЙ
  старый/сломанный UI (в т.ч. застрявший v552).
- Код ИСПРАВЛЕН: RebuildCats/RebuildJobs объявлены в правильном
  порядке + всё в pcall — UI не падает.
- Дополнительно: в lua/autorun/client лежит тот же v555 (страховка).

## 🎨 ЧТО В UI (F4 + C-меню + прочее)
- **F4**: клик по профe → ПЛАВНО выезжает карточка: имя, описание,
  ОРУЖИЕ списком, ХП/броня, лимит (X/Y), 3D-превью модели,
  кнопка ВЗЯТЬ, переливающийся градиент (HSV-цикл).
- **C-меню**: красивые карточки с переливающейся рамкой при наведении,
  свечение заголовка, золотые секции.
- Замена эмодзи → Юникод (квадратики убраны), таблички 12 НПС,
  мастер-палитра, Derma-патчи.
