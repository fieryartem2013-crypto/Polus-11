# 📋 ПАТЧ-НОУТ v5.8.28 — «ЗАМОК · ESC · ХП · ТЕМП · СТОЙКА»
**Дата:** 23.08.2026 · **Сборка:** POLUS11_SERVER_v5.8.28.zip

> Старые файлы не тронуты. Всё — новые autorun-файлы.

## 1) STAFF LEADER НЕ ВЫДАЁТ «ADMINISTRATOR»
- Staff Leader выдаёт **только явный список** (конфиг):
  User / VIP / Faction Officer / Faction Leader / Helper / Moderator.
- Ранг **Administrator** исключён наглухо (даже если кто-то допишет его в JSON).
- Попытка выдать запрещённый ранг: действие блокируется, в чат —
  «У вас нет прав для выдачи этого ранга», в лог —
  `garrysmod/data/polus_framework/rank_grant.log`
  (дата, SteamID, запрашиваемый ранг, цель).
- Список правится файлом `garrysmod/data/polus_framework/rank_grant.json`
  (создаётся сам при старте). Перечитать: `p11_rankgrant_reload` (Глава).
- Chief Staff Leader и Глава — по старым правилам (ниже себя).

## 2) ESC В E-МЕНЮ БОЛЬШЕ НЕ ВЕШАЕТ ИГРУ
- Esc закрывает круглое E-меню и **возвращает управление**:
  ходьба, инвентарь, другие меню, E по миру.
- Пауза движка после Esc гасится, залипший курсор снимается.
- Alt+F4 по-прежнему закрывает игру — но больше не единственный выход.

## 3) СМЕНА ПРОФЫ СТАВИТ ХП ПРОФЫ
- Взял штурмовика (125) — здоровье и броня становятся цифрами должности,
  а не остаются со старой (100).
- Активное Нечто (когти / 400 ХП) не сбивается.

## 4) ИГРОК МЕДЛЕННЕЕ
- Шаг / бег / прыжок × **0.76** (≈ 130 / 250 / 105 вместо 170 / 330 / 120).
- Живой тюнер без рестарта: `p11_speed 0.76` (0.4…1.5).

## 5) ВСЕ НПС ВЫВЕДЕНЫ ИЗ T-POSE
- Кадровик, ларёк, дежурный, нарядник, караул, связной, автосалоны:
  idle_all_01 / ACT_IDLE + кадр каждый тик на клиенте.
- Старые файлы энтити не редактировались.

## ⚠️ УСТАНОВКА
1. Останови сервер.
2. Удали на сервере `garrysmod/gamemodes/polus/` (или `darkrp/`, если хост так назван) и `garrysmod/lua/autorun/`.
3. Скопируй новую `garrysmod/` ЦЕЛИКОМ.
4. Запусти сервер. Клиентам — перезапустить игру + удалить `garrysmod/cache/`.

## ПРОВЕРКА
- Staff Leader в `/menu` → АДМИНКИ → клик «Administrator» → отказ в чат, строка в `rank_grant.log`. Helper выдаётся.
- Смотришь на игрока, держишь E → меню → Esc → сразу ходишь, открывается C / F4.
- Сменил профу в F4 → полоска ХП = ХП новой должности.
- Бег заметно спокойнее.
- Кадровик / ларёк стоят в idle, не буквой «Т».
