# 📋 ПАТЧ-НОУТ v5.6.9 — «ЗАЩИТА ОТ NULL PANEL (Q-меню)»
**Дата:** 14.08.2026 · **Сборка:** POLUS11_SERVER_v5.6.9.zip

> 📌 Правило соблюдено: старые файлы не тронуты.

## 🔧 ПРОБЛЕМА
Ошибка при клике в Q-меню (спавн-меню):
```
[ERROR] spawnmenu.lua:44: Tried to use a NULL Panel!
SetVisible / DoClick / OnMouseReleased
```
Причина: панель кнопки уже удалена (наш модуль прячет вкладки Q-меню,
+ быстрые клики) — стоковый код движка не проверяет IsValid.

## ✅ РЕШЕНИЕ (глобальный guard)
Добавлен в `fixboot/cl_init.lua` (доставка клиентам гарантирована):
- `Panel:SetVisible` — если панель мертва → тихо пропускаем;
- `Panel:SetText` (DLabel) — аналогично;
- `DImageButton:DoClick` — защита от клика по мёртвой кнопке.
Ошибка больше не всплывает, меню не ломается.

## ⚠️ УСТАНОВКА

3. Перезапусти сервер. Клиентам — перезапустить игру + удалить cache/.
