## 💬 1) НОВЫЙ АДДОН HIDE CHAT v1.0.0 (встроен в сборку)
`garrysmod/addons/hidechat/` — отдельный аддон, ложится штатно:

| Файл | Что делает |
|---|---|
| `lua/autorun/server/hidechat.lua` | сервер: состояние по SteamID64, net, сохранение в `data/hidechat.json`, спавн энтити-«курьера» |
| `lua/entities/polus_p11_hidechat/shared.lua` | описание энтити (point, не спавнится вручную) |
| `lua/entities/polus_p11_hidechat/init.lua` | служебная «пустышка» — курьер клиентского кода |
| `lua/entities/polus_p11_hidechat/cl_init.lua` | клиент: Y/U тумблер, Enter — поле ввода, блокировка вывода |

### Как работает
- Чат скрыт у каждого игрока **по умолчанию**.
- **Y** (и **U** — командный чат) — показать/скрыть (тумблер).
- **Enter** — открыть поле ввода (когда чат показан).
- Состояние хранится на сервере по SteamID64 и **переживает
  переподключение и рестарт сервера** (`data/hidechat.json`).
- Синхронизация индивидуальная: `PlayerInitialSpawn` → сервер шлёт
  состояние игроку; `PlayerDisconnected` → сохранение.

### Почему клиентская часть в энтити
На сервере `sv_allowcslua 0` → `lua/autorun/client` до клиентов
не доходит. Файлы энтити (cl_init.lua) раздаются всем игрокам ВСЕГДА
(паттерн fixboot / infoboot / f4boot — проверен на бою). Сервер
спавнит невидимую энтити под картой `Vector(0,0,-20000)`.

### Сетевые каналы (уникальные)
- `HideChat_Toggle` — клиент → сервер (переключить)
- `HideChat_State` — сервер → клиент (новое состояние, bool)

## ⚠️ УСТАНОВКА
1. Удали на сервере папки `garrysmod/lua/autorun/` и `garrysmod/gamemodes/polus/`.
2. Скопируй новую `garrysmod/` из архива ЦЕЛИКОМ (вместе с `addons/hidechat`).
3. Перезапусти сервер. Клиентам — перезапустить игру + удалить cache/.

## ПРОВЕРКА
- После захода в чат ничего не видно (окно скрыто).
- Нажми **Y** — чат появится, **Enter** — поле ввода, ещё раз **Y** — скроется.
- Переподключись — состояние чата сохранится (кто включил — у того останется).
