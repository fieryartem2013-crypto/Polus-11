### 2.4 Тех-хвосты (из OAT-аналитики и HANDOFF)

- **Смоук-тест в живом GMod так и не проведён** — весь код проверен статикой (luac/парсер), runtime-баги ловятся на сервере. Это задача №0 для v5.0.
- **Единый UI до конца**: админка / F4 / терминал / экономика живут в разных стилях (p11_cl_uistyle начал, но не довёл).
- **Авто-бэкапы** `data/*.json` в `.bak` перед перезаписью — защита от битого JSON на хостинге.
- **Оптимизация на 32+ слотах**: замер таймеров/Think, кэширование TAB-строк (скорборд пересоздаёт панели).
- **Верхний предел team id = 256** — должностей 200+, под ~40 кастомных лимит. При росте — чистить неиспользуемые.

## 3. ПЛАН v5.0 «ФИНАЛ ЭРЫ 4» — 3 релиза + 1 финальный

> Формат эры: одна заявка → один релиз с коднеймом. Так и идём.

### 🎯 v4.34.0 «КАРАНТИН» (закрывает хвост №1 эры) — M
**Заявка владельца (обдумывалась с 09.08):** процедура КАРАНТИНА НКВД.

- Следователь НКВД (ранг/профа) заводит **ПОДОЗРЕНИЕ** на бойца через C-меню/терминал:
  доводы (улики-планшет, показания, «вело себя странно»).
- **ГОЛОСОВАНИЕ ОФИЦЕРОВ** (комиссар/генералы РККА + НКВД + Глава): 60 сек, «за/против/воздержался».
- Принято → **ИЗОЛЯТОР 3 мин**: боец заперт (наручники-ячейка), без рации.
- **ТЕСТ С ДВУМЯ СВИДЕТЕЛЯМИ**: два свидетеля (назначает следователь) присутствуют при анализе крови; результат — в протокол.
- **Ошибочный изолятор** (боец чист) → штраф следователю (10 000₽ в казну) + запись в досье.
- Нечто в изоляторе → «побег из изолятора» сценой (нечестная игра не нужна: срабатывает детект личины при тесте — классика).

**Что даёт:** НКВД получает полноценную процедуру вместо «гадания», станция — ритуал коллективного страха, The Thing-жанр закрывается полностью (подозрение → процедура → вердикт).

### 🎯 v4.35.0 «ХИРУРГ» (хвост №2) — M
**Заявка:** ранния + носилки + госпиталь.

- **Крит-урон**: при HP<15% шанс ранения: «рука» (неточная стрельба/долгая перезарядка) / «нога» (замедление, нельзя бежать).
- **НОСИЛКИ** (новый свеп-предмет у медиков/грузчиков): два бойца несут раненого (он ложится), скорость пары снижена.
- **САНИТАРКА** (уже продаётся в гараже!) принимает раненого: E по машине → везёт в медбей.
- **МЕДБЕЙ-СТОЛ**: процедура лечения (миниигра «инъекция», 3 точные точки — из банка идей №2) → гипс/повязка, ранение снято.
- Без лечения раненый теряет HP медленно (кровотечение) — медик нужен КАЖДОМУ.

**Что даёт:** ценность медслужбы ↑↑, санитарка из «понтов» превращается в рабочий инструмент, экшен на улицах (несут раненого — прикрывай!).

### 🎯 v4.36.0 «ДОСЬЕ» (хвосты №17 + 24 + 26 + 12 — малый пак) — S×4
**Заявка:** «собери мелочь, которая делала станцию живой».

1. **ДОСЬЕ НКВД на терминале** (S): лента инцидентов за смену — тесты/аресты/карантины/розыски/допросы, читается следователями. (частично есть в уликах — довести до терминала)
2. **ОБРАТНЫЙ ВЫКУП** (S): в ларьке вкладка «СДАТЬ» — стволы за 50% цены, расходка за 25%. Деньги замыкаются в круг.
3. **СКИДКА ДНЯ** (S): в ларьке каждый день (по серверному времени) 1 товар −40%, плашка «🔥 СКИДКА ДНЯ». Причина зайти.
4. **ЧУТЬЁ НЕЧТО** (S): когда лаборант начинает тест крови носителя — Нечто получает тост «ТВОЮ КРОВЬ ПРОВЕРЯЮТ» и 10 сек на побег/подмену результата. Кот-мышка у лаборатории.

### 🎯 v5.0.0 «ЭРА-ФИНАЛ» (хвосты №5/13/27 + 11 — большой финальный аккорд) — L
**Заявка:** «закрой эру 4 тремя системами, которые будут мемом».

1. **ВОРОНКА ИССЛЕДОВАНИЙ** (L, идея №5): образцы массы/спор/крови → исследования на лабораторном столе → ОТКРЫТИЯ Lv1–3:
   - Lv1 «Стабильный реагент» — станция +10% урона по Нечто;
   - Lv2 «Тепловой контур» — генератор тратит −20% топлива;
   - Lv3 «Сыворотка-блокиратор» — инкубация заражённого замедляется ×2 (продаётся у медиков).
   Учёные получают ВЕЛИКУЮ ЦЕЛЬ, станция — общий прогресс, который виден всем («исследования: 2/3»).
2. **СЕЗОН-ЗАЧЁТ** (L, волна 3 №13): 30-дневный сезон. Очки: медали + контракты + дела + операции. Рейтинг сезона в TAB, топ-1 в конце сезона получает **ЛЕГЕНДАРНЫЙ ЗНАК** (новая медаль «☆ Легенда Сезона» с датой). Причина возвращаться КАЖДЫЙ день.
3. **ИТОГИ СМЕНЫ** (M, идея №27): по команде «смена окончена» (админ/Глава/авто по расписанию) — экран-итог на 20 сек: лучший работник/учёный/стрелок/следователь, звание «ЛУЧШИЙ СМЕНЫ» в TAB на сутки + бонус 5 000₽.
4. **ВТОРАЯ ОСОБЬ** (S, идея №11): при 12+ онлайн — второе окно вакансии Нечто (кадровик). Баланс топового онлайна.
