## 1. ЧТО СЕЙЧАС НА РЫНКЕ GMod RP (2026)

По данным рейтингов серверов (top-games.net, Steam-обсуждения, Reddit r/gmod):

| Тренд | Что это значит для нас |
|---|---|
| **DarkRP перенасыщен** | Классика «умерла» (2013–15 золотой век), большинство серверов — «гибрид» или p2w-PvP-помойки. Игроки устали от шаблонных «ганг-войн». |
| **Выигрывает тема/лора** | Живые серверы строятся вокруг СВОЕГО мира (сюжет, конспирология, выживание, ужасы) — а не набора механик. |
| **Сюжетно-ролевые ниши живы** | HL2RP/SCP-подобные/«противостояние» привлекают лояльных игроков, которые приходят ИГРАТЬ В РОЛЬ, а не фармить. |
| **Еженедельные апдейты** | Серверы-лидеры обновляются каждую неделю («weekly updates»), держат анонсы — это удерживает аудиторию. |
| **Чистый UI + перформанс** | «No lag, clean UI, smooth gameplay» — прямо в описаниях топ-серверов. |
| **Монетизация стандартизирована** | EasyDonate / CraftedStore / Tebex: автовыдача, шаблоны, легально (самозанятый/ИП), комиссия с продажи. У нас мост `p11_donorvip` уже готов. |
| **Сообщество > контент** | Дискорд, ивенты, стори-арки, модерация — решают больше, чем ещё один свеп. |

**Вывод для ПОЛЮС-11:** у нас есть то, чего нет у 90% серверов, — **уникальный мир** («Нечто» на полярной станции, паранойя, маскировки, НКВД-расследования). Это наша «фишка», которую нужно усиливать, а не закапывать под ещё одним батл-пассом. Игрок приходит за АТМОСФЕРОЙ и ПАРАНОЙЕЙ.

## 2. НАША НИША И СИЛЬНЫЕ СТОРОНЫ (что нельзя ломать)

1. **«Нечто»** — сердце проекта: заражение, маскировка, поглощение личностей. Аналогов нет.
2. **Холод/станция/выживание** — атмосфера закрытого объекта.
3. **Советский стиль** — редкая тема, цепляет взрослую аудиторию.
4. **Сервер-авторитетная экономика** — нет читов с деньгами.
5. **Продуманная модерация и админка** — ранги, вайтлист, замок консоли.
6. **Весь контент стоковый** — порог входа низкий (не нужны паки).

**Слабые стороны (честно):**
- Техдолг: 4 поколения кода Нечто, мёртвые системы, монстр-комментарий.
- Нет сюжетных ивентов «из коробки» — ивенты руками админа.
- Онбординг для новичка всё ещё сложный (много систем).
- Донат-витрина «плашка-заглушка» → ДС (это ок, но можно больше).
- Нет статистики/веб-дашборда для владельца.

## 3. ИДЕИ КОНТЕНТА (большой список, сгруппирован)

### 🎭 Геймплей/атмосфера (ядро эры 6)
1. **«Карантинная тревога»** — авто-ивент: при подозрении на Нечто (2+ заражённых, убийство на виду) станция входит в фазу «КАРАНТИН»: сирена, закрытие секций (телепорт-барьеры), обязательная проверка крови всех у медпункта, оцепление НКВД. Всё уже частично есть (фазы, кровь, досье) — связать в один сценарий.
2. **«Алиби и допрос»** — НКВД допрашивает с таймером: игрок выбирает «где я был» из карточки (маркеры его передвижений за последние N минут). Нечто вынуждено врать убедительно. Делает расследования настоящими.
3. **Процедурные происшествия** — каждые 20–40 минут случайное событие: обрыв связи, замыкание, «сигнал с поверхности», пропажа припасов, крик в вентиляции. Разнообразит смену без админа.
4. **Журнал станции / радиопостановки** — периодические «объявления диктора» (текст+звук) для атмосферы: сводка погоды, приказы, «пропал без вести: …».
5. **Медицинская напряжёнка** — нехватка лекарств зимой: уколы и антидоты на вес золота, медсёстры — ключевые лица (уже есть зачатки — усилить).

### 💰 Экономика и донат (без p2w-перекоса)
6. **Донат = косметика и удобство, не сила:** скины/облики, позывные, эмблемы на броне, «именной паёк», закреп в TAB. Никакой «+100 HP за донат» — это убивает РП (урок DarkRP).
7. **Сезонный магазин «ПОЛЯРНАЯ ВЫРУЧКА»** — 1 раз в месяц: 3–5 эксклюзивных косметических позиций, скидка дня, «золотая подписка» (VIP) с мелочами: +1 слот в гардеробе, кастомный цвет плашки, приоритетная очередь на вакансию Нечто (НЕ сама вакансия!).
8. **Аукцион «ТРОФЕИ СТАНЦИИ»** — раз в неделю админ устраивает аукцион (ивент-лотерея за ПФ): уникальные модели/прозвища. Игроки сжигают накопленный ПФ.
9. **Батл-пасс сезонами** — сезон «Битва Времени» уже был — теперь сезоны по 4–6 недель с ТЕМОЙ (зима/ледокол/экспедиция), награды-модели и профы. Привязка сезона к git-тегу.
10. **«Складские заказы»** — донат-позиции, которые выдают НЕ мгновенно, а «прибывают с колонной» через 10–30 минут (атмосферно + анти-спам).

### 👥 Фракции и соцмеханики
11. **Славы и звания смены** — уже есть; развить: «Лучший смены» получает флажок-плашку в TAB на сутки + приоритет в выборе поста.
12. **Напарничество** — бонус РП за работу в паре (патруль вдвоём = +XP дежурства), «шефство» над новичком (ментор получает медаль).
13. **Семейные/личные тайники** — у каждого своя ячейка в сейфе уже есть; добавить «личный дневник» (заметки, которые видны при обыске НКВД) — идеально для РП и расследований.
14. **Внутренние разборки фракций** — НКВД vs РККА: отчёты, проверки, «подозреваемые» — механики уже есть (досье/штрафы), добавить сюжетную завязку.

### 🤖 Нечто (усилить сердце)
15. **«Память жертвы»** — Нечто, поглотив игрока, получает фрагменты его «памяти» (последние действия/место) и может врать убедительнее в допросах. Уже есть Разум жертвы — расширить.
16. **Двойная игра на выживание** — заражённый в инкубации получает «голос твари» в уши (шепот), но обязан играть человека: станет мемом «кто из нас».
17. **Нечто-фаза «Прорыв»** — финал смены: тварь раскрывается, станция в осаде, задача — дожить до смены караула. Эпик-финал смены.

### 🧰 QoL и техника (для удержания)
18. **Маяки/подсказки** — уже есть POI; добавить «первый час новичка»: пошаговый чек-лист с прогрессом (уже есть онбординг — довести до ума).
19. **Счётчик стажа и званий** — уже есть; добавить ачивки-«вехи» (первые 10 смен, 100 тестов, 50 дежурств) с плашками.
20. **Статистика в TAB** — вкладка «КАРЬЕРА»: часы, дела, медали, kills/deaths, «самое долгое дежурство».
21. **Мгновенный перевод валют игрок→игрок** — уже есть обмен; добавить «перевод по клику в TAB» (с налогом, чтобы не было спама).
22. **Уведомления в Дискорд** — мост «награждение/ивент/репорт» → канал (привлечение и контроль).
23. **Веб-дашборд для владельца** — статистика онлайн, экономика, жалобы (через HTTP на внешний сервис или файл-отчёт).

### 📣 Маркетинг (как наполнять сервер)
24. **Стори-арки** — «сезон сюжета»: раз в 2 недели ивент с развитием (пропала группа, найден дневник, загадка). Анонс в Дискорде за 3 дня.
25. **Еженедельный патч-ноут** — короткий список изменений каждую неделю (мы уже делаем патч-ноуты — публиковать их в Дискорде/на сайте).
26. **Конкурсы РП** — «лучший допрос», «лучший рапорт», «самая красивая личина» — награды медалями/ПФ.
27. **Стримеры/клипы** — приглашать стримеров, делать «моменты станции» (киллфид-клипы) — виральный рост.
28. **Новичковый поток** — «приведи друга»: оба получают паёк/ПФ за совместные 3 смены.
