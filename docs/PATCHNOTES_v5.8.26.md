## 🐛 ПРИЧИНА (найдена)
В GMod **максимальный номер команды (team) = 255**. Все профы
(РККА/НКВД/ООН/Тера) регистрируются как кастомные с team-индексами
**от 200** — то есть всего 56 слотов (200..255).

- раньше проф было 43 → 200+43=243 < 255 ✅
- добавили ООН (9) → 52 → 252 ✅
- добавили **Теру (5) → 57 → 200+57 = 257 > 255** ❌

`team.SetUp(257)` кидал фатальную ошибку **БЕЗ pcall** → цикл
регистрации всех проф прерывался → **пропадали ВСЕ профы**
(не только новые).

## ✅ ЧТО ИСПРАВЛЕНО
1. **База кастомных команд сдвинута 200 → 140** (fw_sv_customjobs.lua
   и fw_sv_seed_rkka.lua): теперь диапазон 140..255 = **116 слотов** —
   хватает на все 57+ проф с запасом.
2. **team.SetUp защищён pcall** (fw_sh_jobs.lua, все 4 места): даже
   если какая-то запись битая/вне лимита — она пропустится, а НЕ
   уронит регистрацию остальных. Профы больше никогда не пропадут
   разом.
3. Новые профы (Тера) встанут на свободные слоты 140..199; старые
   из сейва останутся на 200+ — конфликтов нет.

## ⚠️ УСТАНОВКА (ВАЖНО)
1. Останови сервер.
2. Удали на сервере папки `garrysmod/gamemodes/darkrp/` и `garrysmod/lua/autorun/`.
3. **Также удали старые data-файлы проф** (создадутся заново):
   - `garrysmod/data/polus_framework/jobs_custom.json`
   - `garrysmod/data/polus_framework/factions.json`
   (удали папку `garrysmod/data/polus_framework/` целиком — там только
   профы/фракции/вайтлисты, пересоздадутся сами)
4. Скопируй новую `garrysmod/` ЦЕЛИКОМ.
5. Запусти сервер. Клиентам — перезапустить игру + удалить cache/.
