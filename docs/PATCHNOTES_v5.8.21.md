## 🎯 1) КОНТЕКСТНОЕ МЕНЮ ПО Е (на игроке)
Смотришь на игрока (до 250 юнитов) и **удерживаешь Е ~0.7 сек** →
открывается меню действий:

| Кнопка | Что делает |
|---|---|
| 💰 Передать деньги | из своего кошелька (1–50 000₽) |
| 👋 Подозвать | жест «Сюда!» |
| 📄 Показать документы | твоё удостоверение открывается у него в окне |
| 💨 Толкнуть | лёгкий пинок |
| ⭐ Выдать опыт (командир) | опыт службы (древо), макс 1000 за раз |
| 🔫 Оружие из багажа | случайный ствол из твоего багажа → ему в руки |

- **Опыт выдают командиры/генералы фракций** (должности с command=true,
  включая Командира ГОК, или ранг Head Admin+); лимит 1000;
- быстрый тап Е — обычное использование (на НПС/энтити — как раньше);
- все действия — с проверкой дистанции и живости, анти-спам 0.6 сек;
- «толкнуть» и «оружие» логируются в журнал.

## 📐 2) ЧЕРТЕЖИ ОРУЖИЯ ДЛЯ КРАФТА
Новые предметы в ларьке (материалы мастерской):

| Чертёж | Цена | Рецепт на верстаке (!крафт) |
|---|---|---|
| Чертёж «АК-74» | 5 000₽ | чертёж + лом 3 + запчасти 2 + спирт → АК-74 |
| Чертёж «СВД Драгунова» | 7 000₽ | чертёж + лом 4 + запчасти 3 + спирт 2 → СВД |
| Чертёж «РПК-16» | 8 000₽ | чертёж + лом 5 + запчасти 3 + соляра → РПК-16 |
| Чертёж «Кустарный огнемёт» | 4 000₽ | чертёж + соляра 3 + запчасти 2 + лом 2 → огнемёт |

Собранное — в инвентарь (🎒), оттуда «ИСПОЛЬЗОВАТЬ» → в руки.
Нужен ARC9-пак для EFT-стволов (как у проф); без пака сервер
честно скажет «не собрать».

## ⚠️ УСТАНОВКА
1. Удали на сервере `garrysmod/gamemodes/darkrp/` и `garrysmod/lua/autorun/`.
2. Скопируй новую `garrysmod/` ЦЕЛИКОМ.
3. Перезапусти сервер. Клиентам — перезапустить игру + удалить cache/.

## ПРОВЕРКА
- Наведись на игрока, удержи Е 0.7 сек → меню. Передай деньги/покажи
  документы/толкни. Командир — выдай опыт (макс 1000).
- Купи чертёж в ларьке, подойди к верстаку (!крафт) → рецепт соберётся.
