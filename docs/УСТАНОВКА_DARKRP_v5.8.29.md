# 🧊 УСТАНОВКА v5.8.29 — гейммод `darkrp`

**Новый файл. Заменяет собой разделы про пути и запуск в `INSTALL.md`**
(там ещё написано `gamemodes/polus` и `+gamemode polus` — это устарело с v5.8.29).

## ШАГ 1. Куда кидать

В архиве лежит папка `garrysmod/`. Её содержимое копируется **поверх**
`garrysmod/` сервера:

| Что в архиве | Куда попадёт | Зачем |
|---|---|---|
| `garrysmod/gamemodes/darkrp/` | `garrysmod/gamemodes/darkrp/` | сам гейммод ПОЛЮС-11 |
| `garrysmod/lua/autorun/…` | `garrysmod/lua/autorun/…` | патчи v5.2.5…v5.8.29 (грузятся сами) |
| `garrysmod/sound/polus11/` | `garrysmod/sound/polus11/` | музыка станции |
| `garrysmod/cfg/server.cfg` | `garrysmod/cfg/server.cfg` | хостнейм, лимиты, `gamemode darkrp` |

⚠️ **Если на сервере уже стоит настоящий DarkRP** — убери одну из двух папок
`garrysmod/gamemodes/darkrp/`. Две папки с одним именем = конфликт, загрузится
непонятно что.

⚠️ **Не ставь рядом старые аддоны** `polus_framework`, `polus11`, `prof_npc`,
`thing_swep` — их код уже внутри гейммода, двойная загрузка ломает хуки.

## ШАГ 2. Запуск

```
srcds.exe -game garrysmod -console +gamemode darkrp +map gm_flatgrass -maxplayers 24
```

На хостинге в панели: **Gamemode = `darkrp`**.

## ШАГ 3. Ключ основателя (обязательно!)

С v5.8.29 ключ **не** лежит в коде. При первом старте сервер сам создаёт
`garrysmod/data/polus11/founder.key` и печатает ключ в консоль:

```
[POLUS-11] КЛЮЧ: <32 символа>
[POLUS-11] Вход:  p11_access <32 символа>
```

Полезные команды (только из консоли **сервера**):

| Команда | Что делает |
|---|---|
| `p11_founderkey_show` | показать текущий ключ |
| `p11_founderkey_reset` | выпустить новый ключ |

Старый ключ `АрчиславКрутойПарень2013` **не работает** — он был опубликован
в открытом репозитории, считать его скомпрометированным.

## ШАГ 4. Проверка (5 минут)

1. `lua_run print(POLUS_BUILD)` → `5.8.29` (в консоли сервера и в консоли клиента).
2. В сервер-браузере сервер виден как **DarkRP**.
3. `!сбор тренировка` → у всех баннер причины и маркер, через 60 с — «явились X из Y».
4. `p11_access АрчиславКрутойПарень2013` → отказ.
5. Обычным игроком `!профа Начальник НКВД` → отказ (нужен Helper+).
6. На посту постоять 4 минуты без движения → «🛑 Пост не засчитан».

## Тюнинг новых механизмов (консоль сервера, без рестарта)

| Конвар | По умолчанию | Смысл |
|---|---|---|
| `p11_profa_minlevel` | `2` | с какого ранга можно менять название должности (0 = всем) |
| `p11_duty_afk` | `240` | секунд без движения = АФК на посту (0 = выключить проверку) |
| `p11_duty_move` | `40` | какое смещение считается движением, юн. |
| `p11_dutywage` | `100` | оклад дежурного за минуту, ₽ |
