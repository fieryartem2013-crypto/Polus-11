## 📥 1) ЖЕЛЕЗОБЕТОННАЯ РАЗДАЧА ТРЕКА polus_ost_1
`lua/autorun/server/p11_sv_dlfix_spawn_v583.lua` — «на всякий случай»:
- явно регистрирует `polus_ost_1` для скачивания клиентам
  (resource.AddFile — игроки качают при заходе, один раз, дальше кэш);
- находит файл по имени с ЛЮБЫМ расширением: `polus_ost_1.mp3`,
  `.wav`, `.ogg` — регистр не важен;
- каждые 60 сек перепроверяет: файл можно добавить БЕЗ рестарта
  (новые игроки скачают; старые — при перезаходе);
- если файла ещё нет — не падает, спокойно ждёт и пишет в консоль,
  что делать.

### Что сделать тебе
Положи файл в `garrysmod/sound/polus11/music/polus_ost_1.mp3`
(название латиницей, без пробелов) → рестарт сервера → готово.

## 🎛 2) НОВОЕ: ИГРА ПО ИМЕНИ
Команды (админ):
- `!музыка polus_ost_1` — сыграть трек по имени (можно кусок имени,
  регистр не важен);
- `!музыка` — список; `!музыка 2` — по номеру;
- `!музстоп` — стоп; `!музгром 0.5` — громкость.

Обработчик `!музыка` переустановлен (страховка от двойной обработки:
наш скрипт снимает старый и ставит свой последним, повторы через
таймеры 1/3/6 сек).
