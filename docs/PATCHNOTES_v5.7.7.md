**Дата:** 15.08.2026 · **Сборка:** POLUS11_SERVER_v5.7.7.zip

> 📌 Правило соблюдено: старые файлы не тронуты, всё новое.

## 🎭 1) КНОПКА «ВНЕШНОСТЬ» В С-МЕНЮ (управление бодигруппами)
Зажал **C** → в меню появилась кнопка **«🎭 Внешность»** (правая колонка
под «Меню моделей»; у админов/вайтлиста — левая колонка внизу).

Клик → окно **«ВНЕШНОСТЬ — БОДИГРУППЫ»**:
- каждая группа модели (лицо, головной убор, шевроны, снаряжение…)
  со своим названием и текущим значением;
- **◀ ▶** — изменить вариант, **СБРОС** — конкретную группу в 0,
  **СБРОСИТЬ ВСЮ ВНЕШНОСТЬ** — всё сразу;
- изменение видно сразу у себя, сервер применяет **всем** игрокам.

## 💾 2) СОХРАНЕНИЕ ВНЕШНОСТИ НА СЕРВЕРЕ
`lua/autorun/server/p11_sv_bgmenu_spawn_v577.lua`:
- состояние бодигрупп хранится по SteamID64 (`data/bodygroups.json`),
  переживает переподключение и рестарт сервера;
- при спавне/заходе внешность восстанавливается автоматически
  (с защитой: чужие/несуществующие группы на новой модели пропускаются);
- net-канал `P11_BGSet` (уникальный), лимиты и проверки — на сервере.

## 📦 3) ФАЙЛЫ (все новые)
| Файл | Роль |

| `gamemodes/polus/entities/entities/polus_p11_bgmenu/shared.lua` | описание энтити (point) |

сам файл `p11_cl_cmenu.lua` НЕ тронут. Клиент доставляется через
cl_init энтити (работает при `sv_allowcslua 0`, паттерн fixboot).

## ⚠️ УСТАНОВКА
1. Удали на сервере папки `garrysmod/lua/autorun/` и `garrysmod/gamemodes/polus/`.
2. Скопируй новую `garrysmod/` из архива ЦЕЛИКОМ.
3. Перезапусти сервер. Клиентам — перезапустить игру + удалить cache/.
