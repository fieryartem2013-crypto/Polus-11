---

## 1. Что такое наш продукт (позиционирование)

ПОЛЮС-11 — **социальный хоррор-детектив с сим-элементами станции**. Формула удержания игрока:

```
РУТИНА (дела/миниигры/экономика)  →  ПОДОЗРЕНИЕ (кто-то не работает?)
→  ПАРАНОЙЯ (тесты/допросы)  →  ХАОС (явление Нечто)  →  РУТИНА...
```

Рутина — не отвлечение, а **топливо паранойи**: тот, кто НЕ делает своё дело — подозреваемый. Поэтому v4.1 «у каждого своё дело» — прямое усиление ядра.

## 3. SWOT под ОАТ

**Сильные стороны**
- Уникальная механика «роль Нечто через кадровика» — никто не знает, кто взял вакансию.
- Станция как живой организм (свет/топливо/износ) → у игроков всегда «чем заняться».
- Полный цикл власти: НКВД-допросы и РККА-приказы дают сюжеты без админов.
- Экономика с долгим хранением (сейф) → возвращаемость.

**Слабые стороны**
1. **He все должности «с делом»**: повар/медик/грузчик — без своих миниигр (у них только старые задачи). ⚠ приоритет v4.2.
2. **Нет обучалки**: новичок читает F1, но не проходит руки. Нужен интерактивный «первый час» (подсказки-стрелки на 10 минут).
3. **Пиковая нагрузка на Lua**: множество систем тикают по таймерам; на 32+ слотах нужен замер `timer`/`Think`-стоимости.
4. **Визуальная целостность**: UI окна живут в 3 разных стилях (fw_cl_admin, p11_eco, p11_help) — начат объединяющий P11UI, надо довести до конца.
5. **Античит базовый**: проверки на входящих пакетах миниигр есть, но общего слоя (speedcheck движения, net-spam guard) нет.

**Возможности**
- EFT-витрина → «охота за трофеями» как мета-цикл.
- RP науки → воронка исследований (доклады открывают бонусы станции).
- Патрули → «сменные наряды» (капитан формирует пары реально).

**Риски запуска**
- Нечто-игрок сливает раунд скоростью убийств → нужен soft-cap агрессии и «инкубация» уже есть; добавить охлаждение убийств подряд.
- Новичок-Нечто не понимает R/!форма → туториал-минигайд для заражённого (всплывашка при инфекции).
- Чат-накрутки деньгами репортом — ограничить суточный лимит p11_givemoney.

## 4. Метрики ОАТ (что смотреть ежедневно)

| Метрика | Цель | Сигнал беды |
|---|---|---|
| DAU / пиковый онлайн | 20+ / 40+ | <10 |
| Ср. длина сессии | 35+ мин | <15 мин (первые часы не цепляют) |
| % игроков в должности к 5-й минуте | >80% | <50% (онбординг) |
| % смен с хотя бы 1 явлением Нечто | >70% | <40% (скучно) |
| Винрейт станции (Нечто мёртв) | 45–55% | <30% или >75% |
| Оборот рублей/игрок/сессия | 1–3 тыс. | <300 (экономика не вовлекает) |
| Тестов крови за смену | 3–8 | 0–1 (паранойи не заводится) |
| Кол-во RP у топ-учёного | 15+ | ≈0 (лаба мертва) |

Тех: SERVER tick <20 мс при 32 слотах; число Lua-ошибок в консоле = 0 за час; сетевой объём/клиент <80 кБ/с.

## 5. План доводки к открытию (рекомендованный бэклог)

**P0 — до запуска ОАТ (v4.2):**
1. Дела для повара/медика/грузчика (миниигры: готовка×3 шага, лечение-процедура, погрузка-ритм).
2. Туториал новичка: 5 стрелок-подсказок в первые 10 минут (void UI-поинтеры).
3. Сетевой анти-спам (rate-limit всех net.Receive) + журнал подозрительного.
4. Мягкий баланс Нечто: кулдаун поглощений 45с чтобы 16 игроков не исчезали за 5 минут.
5. Единый P11UI для fw_cl_admin и экономики (дизайн-консистентность).

**P1 — в первую неделю ОАТ (v4.3):**
6. Воронка научных исследований: 3 уровня грантов (250/600/1500₽) с лор-бумагами.
7. «Наряды» патруля: командир собирает дуэт, бонус за обход вдвоём.
8. Журнал инцидентов НКВД (записи арестов/тестов → терминал досье).
9. Конец смены: экран «ИТОГИ СМЕНЫ» (лучший работник/стрелок/учёный) — мета-мотивация.
10. Погодные события: белая мгла (равномерный дебафф видимости) — новая фаза.

**P2 — контент-месяц (v5.0):**
11. Карта-событие «Пожар в блоке В» (огнетушители как новый свеп).
12. Мутации Нечто за поглощения (уже в бэклоге) + третья форма «Ползун».
13. Голосование «экстренный сбор» (подозрение+выгнать в метель) — гражданский детектив.
14. Достижения станции (спрайты в TAB).

## 7. Итог

Сборка v4.1 закрывает главный разрыв «а чем заняться простому бойцу» — это был главный риск удержания после эйфории первого явления Нечто. Ключевой риск, оставшийся красным: **баланс агрессии Нечто в полном онлайне** — мониторить ежедневно по метрике «винрейт станции».
