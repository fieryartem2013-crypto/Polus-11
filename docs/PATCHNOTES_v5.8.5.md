# 📋 ПАТЧ-НОУТ v5.8.5 — «МУЗЫКА АВТОМАТОМ + ПОВТОР»
**Дата:** 15.08.2026 · **Сборка:** POLUS11_SERVER_v5.8.5.zip

> 📌 Старые файлы не тронуты, всё новое.

## 🔁 ЧТО ИЗМЕНИЛОСЬ (по заявке «не один раз, а автоматом»)
Раньше: трек играл один раз, только по команде админа.
Теперь: **фоновая музыка станции** — включается сама и повторяется.

## 🎵 1) АВТОВКЛЮЧЕНИЕ
- **при старте сервера / смене карты** — через ~6 сек сама играет
  музыка: `polus_ost_1`, если файл есть; иначе первый трек из
  `sound/polus11/music/`;
- **каждому заходящему игроку** — через 3 сек после спавна
  автоматически уходит текущий трек: новичок слышит музыку сразу,
  без всяких команд.

## 🔄 2) ПОВТОР ПО КРУГУ (по умолчанию ВКЛ)
Трек зациклен — играет бесконечно, как эмбиент-фон станции
(теперь это фича, а не баг 😄). Выключить повтор: `!музцикл 0`.

## 🔊 3) ГРОМКО
Громкость по умолчанию 1.0 (максимум). Регулировка: `!музгром 0.5`.

## 🎛 КОМАНДЫ (админ)
| Команда | Что делает |
|---|---|
| `!музыка` | список + что играет + повтор/громкость |
| `!музыка 2` / `!музыка polus_ost_1` | сменить трек (по номеру / имени) |
| `!музыка стоп` / `!музстоп` | остановить (авто больше не играет до смены карты / новой команды) |
| `!музгром 1.0` | громкость 0..1 (по умолчанию 1.0) |
| `!музцикл 1` / `!музцикл 0` | повтор вкл / выкл (по умолчанию ВКЛ) |

Клиентский плеер v2 (musicloop, sound.PlayFile с loop-флагом) —

последним (таймеры до 24 сек) — активным остаётся именно этот.

## ⚠️ УСТАНОВКА
1. Удали на сервере папки `garrysmod/gamemodes/darkrp/` и `garrysmod/lua/autorun/`.
2. Скопируй новую `garrysmod/` ЦЕЛИКОМ.
3. Перезапусти сервер. Клиентам — перезапустить игру + удалить cache/.

## ПРОВЕРКА
- После рестарта сервера через ~6 сек музыка играет САМА (громко, по кругу).
- Зайди на сервер новым игроком — через 3 сек слышишь ту же музыку.
- `!музстоп` → тишина; `!музыка 1` → снова играет.
