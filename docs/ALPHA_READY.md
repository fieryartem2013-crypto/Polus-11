## 2) ОБЯЗАТЕЛЬНЫЙ SMOKE-ТЕСТ ПЕРЕД АЛЬФОЙ (15 минут, 1 админ + 2 игрока)

1. Заход → надпись `[POLUS-11 v2.2] Аддон активен`, консоль: `[P11FW v1.2] Сервер: 5/5 модулей, профессий: 7`
2. **F4** → меню открылось → берёшь «Рядового охраны» → модель/пистолет/рация на месте
3. Админ: `!нпс` → у кадровика по E берёшь «Инженера» → огнемёт в руках
4. Админка (`p11fw_admin`): ИГРОКИ → выбрать второго → **АРЕСТ 1 мин** → у него красная плашка «ВЫ АРЕСТОВАНЫ», стоит в камере без оружия → через минуту освобождён и снаряжение вернулось
5. Там же: **РАБСТВО 1 мин** → плашка, не может поднять оружие и взять профу; **БАН 1 мин** → через 4 сек кик, при входе отказ, через минуту пускает
6. УТИЛИТЫ: поставить спавн-поинт (смерть/реконнект → респавн там), точку ареста, удалить
7. ДОЛЖНОСТИ: создать «Киномеханик» (своя модель + weapon_polus11_radio) → появилась в F4 → перезапуск карты → **должность НА МЕСТЕ** (сохранилась)
8. Пульт (`!пульт`): случайный пациент-ноль → у заражённого через 2.5–4.5 мин когти → убить игрока → R по трупу → модель/имя жертвы → R → вернул себя
9. Учёный: шприц → забор крови → колба на стол → E → результат только ему; у военного стол писать должен отказ
10. Генератор: E — статус; дождаться пустого/саботаж заражённым → блэкаут, заражённые быстрее в темноте; бочка → свет вернулся
11. Огнемёт по заражённому: поджигает и бьёт ×3
12. `/r привет` с рацией на одном канале: шипение + помехи; пульт → буря 90 сек → связь мертва

13. Задачи смены: возьми «Повар» → появился виджет слева → накорми пайком 1 человека → «Накорми экипаж 1/3»
14. Нечто: `!форма поглотитель` → 170 хп → ПКМ по человеку = путы 4 сек; `!форма споровик` → ПКМ облако → человек внутри копит споры → молча заражается; `!крик` — людей отбрасывает
15. Вирусолог: скальпель в руки → вскрытие трупа → вердикт в чат всем; заражённый вирусинг жмёт R → результат подделан
16. Блэкаут → химсвет ЛКМ → зелёный свет 10 мин; споровый газ в темноте виден издалека
17. Пульт → «СИРЕНА» → все идут к офицеру → через 7 сек офицеру зачлось построение

Если всё ✓ — сервер готов к закрытой альфе.

## 3) НАСТРОЙКА СЕРВЕРА (server.cfg / запуск)

- `gamemode sandbox` (DarkRP НЕ нужен; если всё же стоит — фреймворк уступает ему F4, оба живут)
- `sv_maxplayers 14–20` — формат паранойи не любит толпу
- Хост должен дать себе админку **на сервере** (superadmin через ULX/samus/встроенное) — иначе пульт и админка не откроются
- Карта: снежная/арктическая, замкнутая (база, коридоры, вентиляции). После загрузки карты один раз в консоль сервера: `nav_generate` (для босса)
- Звук: включён стандартный голос GMod; рация работает через текст + голос по каналу
- Отключи сторонние чистилки трупов — Имитатору нужны тела. Если стоят — белый список для ragdoll'ов игроков
