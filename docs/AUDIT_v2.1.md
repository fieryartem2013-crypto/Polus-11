## 🔧 Прочие правки v2.1

- `polus11_vial`: колба теперь крепится через `SetParentAttachment` — сидит ровно в правой руке (раньше могла висеть у пупа из-за MaintainOffset).
- `polus11_acidspit`: `MOVETYPE_VPHYSICS` вместо FLY (реальная баллистическая дуга вместо «зависания»), добавлен `RENDERMODE_TRANSALPHA` (полупрозрачный зелёный шар, раньше альфа не применялась), Think облегчён до 2 тиков/сек.
- `sv_admin.lua`: убрана мёртвая `util.AddNetworkString("P11_LogPush")` (регистрировалась, но нигде не использовалась).
- Версия в загрузчике поднята до **2.1** — проверка в игре: баннер при входе и команда `polus11_status` покажут `v2.1`.

## ✅ Что проверено и НЕ требует правок

- Загрузчик с pcall и баннером v-версии, `polus11_status` — рабочая диагностика.
- Ядро заражения: инкубация → активация → выдача когтей; улей-синк заражённых; крюк урона (пули ×0.35 / огонь ×3, босс ×5 от огня).
- Генератор: расход топлива, блэкаут по границе, саботаж/ремонт с прогрессом и отменой при движении, урон от пуль, несколько генераторов (блэкаут только когда умерли все).
- Тест крови: результат только тестирующему, подмена заражённым учёным, колба-прыгун при позитиве.
- Имитатор: поглощение трупа (фикс гонки авто-скрытия v2.0 на месте), возврат себя, 5-сек «переваривание».
- Админ-пульт: все 13 действий покрыты, права проверяются на каждом пакете.
- Автосмена: старт/стоп, пациент-ноль по таймеру, фазы, эвакуация.
- Персист станции: JSON-сэйв генераторов/бочек/столов, защита от дублей при загрузке.
- Рации: каналы, буря рубит эфир, заражённый слышит все каналы (голос + текст), гарбл текста.
- Скорборд/неймтаги с подменой ников (авто-выкл под DarkRP).
- **prof_npc** и **thing_swep** — криминальных багов не найдено, логика целостна (proof npc: сохранение/загрузка, смена профы через DarkRP с pcall; thing_swep: маски, яд, скорость — хуки чистые).

## ⚠️ Осталось проверить ТОЛЬКО В ИГРЕ (здесь нет GMod)

1. Энтити видны в Q-меню (категория «ПОЛЮС-11») и спавнятся — поставь папку `polus11` из свежего зипа в `garrysmod/addons/`, **без вложенной папки** (`addons/polus11/lua/...`).
2. Имитатор: убийство → R по трупу → съел → R ещё раз → вернул себя.
3. `flamethrower` теперь реально поджигает: струя по NPC — должны бегать в огне ~3 сек.
4. Босс: на карте нужен navmesh (`nav_generate` в консоли один раз), иначе тупит на месте.
5. Если установлены аддоны, чистящие трупы (corpse decay/remover), — Имитатор может не найти труп: добавь `polus11`-трупы в их белый список или отключи чистку ragdoll'ов игроков.
