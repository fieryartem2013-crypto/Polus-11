==================================================
  МУЗЫКА СТАНЦИИ — как добавить свой трек
==================================================

1) Кинь файл .mp3 (или .wav) В ЭТУ папку:
   garrysmod/sound/polus11/music/

2) Правила имени:
   - только ЛАТИНИЦА и без пробелов:
     ДА:   sovetskiy_vals.mp3
     НЕТ:  мой трек.mp3  /  My Track.mp3
   - расширение .mp3 лучше всего (маленький размер)

3) Перезапусти сервер (или смени карту).
   Сервер сам найдёт файл, сам раздаст его всем игрокам
   (скачается при заходе один раз) и добавит в список.

КОМАНДЫ (админ):
   !музыка           — список треков
   !музыка 2         — играть трек №2 всем
   !музыка стоп      — стоп
   !музстоп          — то же
   !музгром 0.6      — громкость (0..1)

ПРИМЕЧАНИЯ:
   - Размер файла не должен превышать лимит сервера
     (net_maxfilesize 64 = 64 МБ на файл — хватает с запасом).
   - Не называй файлы с кириллицей/пробелами — движок
     Source не любит, у игроков не скачается.
   - Трек играет один раз (не по кругу). Хочешь заново —
     команда ещё раз.
   - Это НЕ авторские права на станции: включай только то,
     что тебе разрешено транслировать (или своё).
