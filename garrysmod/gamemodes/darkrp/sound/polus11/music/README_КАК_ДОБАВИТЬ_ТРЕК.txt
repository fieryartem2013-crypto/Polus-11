==================================================
  МУЗЫКА СТАНЦИИ — как добавить свой трек
  (всё внутри ГЕЙММОДА)
==================================================

Папка с музыкой гейммода:
   garrysmod/gamemodes/darkrp/sound/polus11/music/

1) Кинь файл .mp3 (или .wav) В ЭТУ папку.
2) Правила имени:
   - только ЛАТИНИЦА и без пробелов:
     ДА:   polus_ost_1.mp3
     НЕТ:  мой трек.mp3
   - расширение .mp3 лучше всего (маленький размер)
3) Перезапусти сервер.

Сервер сам найдёт файл, САМ раздаст его всем игрокам при заходе
(resource.AddFile, один раз — дальше кэш) и САМ включит его
фоном по кругу (эмбиент). Если есть polus_ost_1 — играет он,
иначе первый по алфавиту.

КОМАНДЫ (админ):
   !музыка                — список треков
   !музыка 2              — сменить трек (по номеру)
   !музыка polus_ost_1    — сменить трек (по имени)
   !музыка стоп / !музстоп— остановить
   !музгром 1.0           — громкость (0..1, по умолчанию 1.0)
   !музцикл 1 / 0         — повтор по кругу вкл / выкл

ВАЖНО:
   - Это ФОНОВАЯ музыка станции (эмбиент), НЕ интро.
   - Скрипт скачивания и плеер живут в гейммоде:
       gamemodes/darkrp/entities/entities/polus_p11_musicbg/
   - Размер файла < 64 МБ (лимит net_maxfilesize).
   - Не называй файлы кириллицей/с пробелами — не скачается.
   - Включай только то, что можно транслировать (своё/с правами).
