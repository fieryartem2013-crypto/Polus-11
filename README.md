# 🧊 ПОЛЮС-11 RP — «Ледяная Паранойя»

> **1982 год. Антарктида.** Военный гарнизон + научный персонал против
> **Нечто** — существа, которое поглощает жертву и идеально копирует её
> внешность, голос, память и повадки. Military Horror RP по мотивам
> «The Thing» (1982) для Garry's Mod.

## Что это

Готовый **серверный гейммод** (`gamemodes/polus`) — всё в одном, без единого
воркшоп-аддона (только стоковый контент HL2/GMod):

- 🪖 **ПОЛЮС FRAMEWORK** v1.3 — свои профессии (7 штук + редактор в игре),
  F4-меню, NPC-кадровик с сохранением, админ-панель (игроки/должности/утилиты),
  наказания: **арест / рабство / бан** с красным плакатом на экране.
- 🔨 **Строительство для всех** — не-админам доступна только вкладка «Пропы»
  и только вайтлист реквизита станции (~44 модели). Свежий проп — **призрак**
  (прозрачный, без коллизий), E — взять/поставить, **физичным становится,
  только когда рядом никого нет** (анти-грифинг).
- 👽 **ПОЛЮС-11** v2.5 — система заражения с инкубацией, 5 классов Нечто
  (Имитатор, Разделённый, **Поглотитель**, **Споровик**, Тварь-босс),
  кража внешности/имени, генератор + топливо + блэкаут, лаборатория
  анализа крови (можно подделать!), скальпель-вскрытие, рация, сменные
  задачи по профессиям, эффекты паники, химсвет, паёк повара.
- 🔊 Админ-**пульт Нечто** (`!пульт`): заражение, блэкаут, буря, крики,
  босс, сирена переклички и т.д.

## Установка — 5 минут

Смотри **[INSTALL.md](INSTALL.md)** — пошагово, что куда кидать.
Кратко: содержимое папки `garrysmod/` из архива — поверх `garrysmod/` сервера,
запуск `+gamemode polus +map gm_flatgrass`.

## Структура репозитория

```
garrysmod/
├── gamemodes/polus/        ← весь сервер (255 lua-файлов, из них BonChat — 19, MIT)
│   ├── gamemode/           ← ядро гейммода + 116 модулей + бандл чата BonChat (MIT)
│   └── entities/           ← 34 энтити + 17 оружий
└── cfg/server.cfg          ← конфиг сервера
INSTALL.md                  ← инструкция установки
docs/                       ← гайд, аналитика, смоук-тест альфы
```

## Для тестеров (альфа)

- Клиенту качать **ничего не надо** — зашёл и играешь.
- Отчёты об ошибках: консоль клиента/сервера, строки `[POLUS][ERROR]`,
  прикладывай в Issues этого репозитория.
- Смоук-чеклист: `docs/ALPHA_READY.md`.

## 🇺🇸 Аналитика: американское вооружение 1982 года (отряд «Красный Орёл»)

Для шпионских проф ЦРУ подобран арсенал **строго тех времён** — год
действия «The Thing» (1982, станция в Антарктиде). Отобрано то, что
реально стояло на вооружении армии США / использовалось ЦРУ и
спецподразделениями в начале 80-х, и что воспроизводится в сборке БЕЗ
новых аддонов (EFT ARC9 при наличии, иначе точные стоковые HL2-аналоги):

| Реальное оружие (1982) | Почему подходит | В сборке | У кого |
|---|---|---|---|
| **Colt M1911A1** (.45 ACP, с 1911 г.) | Табельный пистолет армии США и личное оружие офицеров/оперативников ЦРУ вплоть до 1985 года | `arc9_eft_m1911a1` (в EFT-паке есть), фолбэк — `weapon_pistol` | Агент, Диверсант |
| **Colt Python** (.357 Magnum, с 1955 г.) | «Роллс-Ройс револьверов» — культовый личный ствол старших офицеров и резидентур | `weapon_357` — модель HL2 и есть Python (попадание 100%, аддон не нужен) | Резидент |
| **Remington 870** (с 1950 г.) | Основной помповый дробовик армии/полиции США в 1982, узкие коридоры станции | `arc9_eft_m870` при наличии пака, фолбэк — `weapon_shotgun` (SPAS-12, 1979 — тоже период, спецназ США) | Диверсант |
| **Оборонительные гранаты** (типа M26/M67) | Сапёрный набор диверсанта | `weapon_frag` | Диверсант |

**Исключение Центра (v4.8.6)**: **Aklys Defense Velociraptor .300
Blackout** — интегрально-глушёный штурмовой автомат (по EFT: класс
`arc9_eft_velociraptor`), выдан Диверсанту «в порядке исключения»:
технически это оружие наших дней, но профиль «тихая ликвидация»
критичен для дела — игра есть игра.

**Сознательно НЕ выдано** (аналитика): MAC-10 и M16A1 — в стоке нет
достойных моделей той эпохи, а современные EFT-M4/UMP ломали бы 1982
год. MP5 — оружие ФРГ (хотя Delta Force его обожала) — оставлен НКВД/
РККА-стрелкам. Резерв на будущее: ADAR-15 из EFT-пака как прокси
гражданского Colt AR-15 SP1 Sporter (1964+) — добавим по заявке.

**Кейс маскировки «ЛЕГАТ»** (`weapon_polus11_disguise`) — по образцу
исторических disguise kit разведчиков (грим, фальш-удостоверение,
китель «чужой» армии в сложенном виде): надевает облик бойца РККА,
липовой позывной, липовую должность и липовой код документа.
