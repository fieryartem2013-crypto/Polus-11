# 🧊 ПОЛЮС-11 RP — «Ледяная Паранойя»

> **1982 год. Антарктида.** Военный гарнизон + научный персонал против
> **Нечто** — существа, которое поглощает жертву и идеально копирует её
> внешность, голос, память и повадки. Military Horror RP по мотивам
> «The Thing» (1982) для Garry's Mod.

## Что это

Готовый **серверный гейммод** (`gamemodes/polus`) — всё в одном, без единого
воркшоп-аддона (только стоковый контент HL2/GMod):

- 🪖 **ПОЛЮС FRAMEWORK** v1.3 — свои профессии (7 штук + редактор в игре),
  F4-меню, NPC-кадровик с сохранением, админ-панель (игроки/должности/утилиты),
  наказания: **арест / рабство / бан** с красным плакатом на экране.
- 🔨 **Строительство для всех** — не-админам доступна только вкладка «Пропы»
  и только вайтлист реквизита станции (~44 модели). Свежий проп — **призрак**
  (прозрачный, без коллизий), E — взять/поставить, **физичным становится,
  только когда рядом никого нет** (анти-грифинг).
- 👽 **ПОЛЮС-11** v2.5 — система заражения с инкубацией, 5 классов Нечто
  (Имитатор, Разделённый, **Поглотитель**, **Споровик**, Тварь-босс),
  кража внешности/имени, генератор + топливо + блэкаут, лаборатория
  анализа крови (можно подделать!), скальпель-вскрытие, рация, сменные
  задачи по профессиям, эффекты паники, химсвет, паёк повара.
- 🔊 Админ-**пульт Нечто** (`!пульт`): заражение, блэкаут, буря, крики,
  босс, сирена переклички и т.д.

## Установка — 5 минут

Смотри **[INSTALL.md](INSTALL.md)** — пошагово, что куда кидать.
Кратко: содержимое папки `garrysmod/` из архива — поверх `garrysmod/` сервера,
запуск `+gamemode polus +map gm_flatgrass`.

## Структура репозитория

```
garrysmod/
├── gamemodes/polus/        ← весь сервер (93 lua-файла)
│   ├── gamemode/           ← ядро гейммода + 46 модулей (17 клиентских)
│   └── entities/           ← 10 энтити + 10 оружий
└── cfg/server.cfg          ← конфиг сервера
INSTALL.md                  ← инструкция установки
docs/                       ← гайд, аналитика, смоук-тест альфы
```

## Для тестеров (альфа)

- Клиенту качать **ничего не надо** — зашёл и играешь.
- Отчёты об ошибках: консоль клиента/сервера, строки `[POLUS][ERROR]`,
  прикладывай в Issues этого репозитория.
- Смоук-чеклист: `docs/ALPHA_READY.md`.
